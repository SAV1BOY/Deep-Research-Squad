# Evidence Language Guide

## Purpose

This guide standardizes how the squad writes about evidence, its quality,
and the confidence it supports. Consistent evidence language prevents
misinterpretation and builds reader trust.

## Evidence Strength Tiers

Use these tiers consistently across all deliverables:

| Tier       | Label              | Description                                      |
|------------|--------------------|--------------------------------------------------|
| Tier 1     | Confirmed          | Multiple independent primary sources agree        |
| Tier 2     | Strong indication  | One primary source plus corroborating secondary   |
| Tier 3     | Moderate indication| Secondary sources agree, no primary contradiction |
| Tier 4     | Weak signal        | Single source or unverified but plausible         |
| Tier 5     | Unverified         | Claim exists but lacks corroboration              |

## Writing About Evidence Quality

### Source Attribution

Always attribute evidence to its source type:
- "Primary data from [source] shows..."
- "According to [secondary source], which cites [primary]..."
- "Industry reporting suggests..." (for aggregated secondary)
- "Anecdotal accounts indicate..." (for unverified)

### Evidence Convergence

When multiple sources point the same direction:
- "Three independent sources converge on the finding that..."
- "Both quantitative data and qualitative interviews support..."
- "Cross-referencing [Source A] with [Source B] confirms..."

### Evidence Divergence

When sources conflict:
- "Source A reports X, while Source B reports Y. The discrepancy..."
- "The quantitative data contradicts the qualitative findings in that..."
- "No consensus exists on this point. The strongest evidence favors..."

## Confidence Level Language

Map evidence tiers to confidence statements:

| Evidence Tier | Confidence Statement                    |
|---------------|-----------------------------------------|
| Tier 1        | "We are confident that..."              |
| Tier 2        | "The evidence strongly suggests..."     |
| Tier 3        | "The evidence suggests..."              |
| Tier 4        | "There are preliminary indications..."  |
| Tier 5        | "It has been claimed, but not verified, that..." |

## Rules

1. Never state a Tier 4-5 finding with Tier 1 language.
2. Always disclose when evidence is single-source.
3. Date-stamp evidence. "As of [date], the data shows..."
4. Distinguish between absence of evidence and evidence of absence.
5. When upgrading or downgrading confidence, explain what changed.

## Common Mistakes

- Using "proves" (research rarely proves; it supports or refutes).
- Treating correlation language as causation language.
- Omitting the date range of the evidence.
- Failing to disclose that a source is interested-party (e.g., vendor research).
- Mixing evidence tiers within a single summary without labeling.
