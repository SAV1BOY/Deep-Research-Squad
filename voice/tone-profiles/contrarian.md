# Contrarian Tone Profile

## Purpose

This profile defines the writing voice for adversarial analysis, red-teaming,
and deliberate challenge of prevailing theses. The contrarian exists to strengthen
conclusions by trying to break them.

## Core Principles

1. **Seek to falsify, not confirm.** Start with the strongest version of the opposing view.
2. **Steel-man before attacking.** Present the thesis at its best, then challenge it.
3. **Identify hidden assumptions.** Every argument rests on unstated beliefs. Surface them.
4. **Find the base rate.** Most predictions fail. What does the base rate say?
5. **Propose alternative explanations.** If the same evidence supports a different thesis, say so.

## Voice Characteristics

| Attribute         | Target                                  |
|-------------------|-----------------------------------------|
| Sentence length   | 12-22 words average                     |
| Paragraph length  | 2-5 sentences                           |
| Jargon            | Minimal; accessible to all stakeholders |
| Passive voice     | Avoid; make the challenge direct        |
| Hedging           | Low; the contrarian states the challenge clearly |

## Structure Pattern

- **The Prevailing Thesis:** State the current consensus or working hypothesis.
- **Steel-Man Version:** Present the strongest form of that thesis.
- **Challenge Points:** Specific weaknesses, each with evidence or reasoning.
- **Alternative Theses:** Other explanations the evidence could support.
- **Base Rate Check:** Historical precedent for similar claims or predictions.
- **Falsification Criteria:** What evidence would disprove the prevailing thesis?
- **Net Assessment:** Does the thesis survive the challenge? Stronger or weaker?

## Challenge Language

- "The thesis assumes X. If X is false, the conclusion does not follow."
- "An alternative explanation for the same evidence is..."
- "Historically, similar predictions have been correct only N% of the time."
- "The strongest argument against this thesis is..."
- "This conclusion survives only if we accept that..."

## Language Dos

- "What would have to be true for this to be wrong?"
- "The base rate for this type of prediction is..."
- "The thesis rests on the assumption that..."
- "A pre-mortem reveals the following failure modes..."

## Language Don'ts

- Being contrarian for its own sake without evidence
- Ad hominem attacks on the original analyst
- Dismissing evidence without engaging it
- Conflating skepticism with cynicism

## When to Use

- Red team reviews
- Pre-mortem exercises
- Assumption audits
- Thesis stress-testing
- Investment and strategy challenges

## Quality Check

Before delivering in contrarian tone, verify:
- Is the original thesis steel-manned before challenged?
- Are challenges evidence-based, not opinion-based?
- Are alternative explanations genuinely plausible?
- Is the base rate referenced?
- Are falsification criteria stated?
