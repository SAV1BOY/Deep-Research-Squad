# Evidence Standards

## Purpose

These standards define what constitutes acceptable evidence for different
types of claims. They ensure that conclusions are supported by sufficient,
diverse, and high-quality evidence.

## Minimum Evidence Requirements

### For Factual Claims
- At least 2 independent sources confirming the fact
- At least 1 source must be Tier 1 or Tier 2
- If only 1 source available, must be flagged as "single-source"
- Contradicting sources must be noted even if outweighed

### For Quantitative Claims (Numbers, Statistics)
- Original source must be identified (not just a citation of a citation)
- Methodology must be noted (survey? census? model? estimate?)
- Sample size must be reported when available
- Date of data collection must be stated
- Margin of error or confidence interval if available

### For Trend Claims ("X is growing/declining")
- Minimum 3 data points over time (2 points is a line, not a trend)
- Time period must be specified
- Base and end points must not be cherry-picked
- External factors affecting the trend must be noted

### For Causal Claims ("X causes Y")
- Must distinguish from correlation explicitly
- Mechanism must be plausible and stated
- Alternative explanations must be addressed
- Ideally supported by experimental or quasi-experimental evidence
- If purely observational, flag as "association, not proven causation"

### For Predictive Claims ("X will happen")
- Base rate or historical precedent must be cited
- Key assumptions must be listed
- Confidence band must be provided (not point estimates)
- Time horizon must be specified
- Track record of predictor/model should be noted if available

## Evidence Quality Grades

| Grade | Definition | Example | Confidence Modifier |
|-------|-----------|---------|-------------------|
| A | Peer-reviewed, replicated, large sample | Meta-analysis | +15 |
| B | Peer-reviewed OR large sample | Single RCT | +10 |
| C | Credible source, methodology disclosed | Think tank report | +5 |
| D | Self-reported, potential bias, small sample | Company survey | +0 |
| F | Unverified, anonymous, conflicted | Blog claim | -10 |

## Evidence Table Requirements

Every research deliverable must include an evidence table that:
1. Lists all evidence for each major claim
2. Grades each piece of evidence (A through F)
3. Notes the direction (supporting/contradicting/partial)
4. Calculates a confidence score using the scoring script
5. Identifies gaps in the evidence base

## Red Lines (Automatic Quality Failure)

- Citing a source that doesn't exist or says something different
- Excluding contradicting evidence without documentation
- Presenting Grade D/F evidence as if it were Grade A/B
- Making causal claims from correlational evidence without caveat
- Providing precise numbers from imprecise sources
- Using outdated evidence for time-sensitive claims without noting the age
