# Patent Databases

## Primary Patent Search Platforms

### Google Patents
- **URL**: patents.google.com
- **Coverage**: 120M+ patents and applications from 100+ patent offices worldwide
- **Strengths**: Free, full-text search, Google Scholar integration, machine translation
- **Key Features**: CPC/IPC classification browse, citation graph, PDF download, prior art search
- **Search Tips**: Use CPC codes for precise technology classification; "claims:" field for claim-specific search
- **Limitations**: Some coverage gaps for non-US jurisdictions; limited analytics
- **Use**: Initial patent landscape search, prior art research, technology scouting

### USPTO (United States Patent and Trademark Office)
- **URL**: patft.uspto.gov (granted), appft.uspto.gov (applications)
- **Coverage**: All US patents and published applications
- **Key Features**: Patent Full-Text Database, PAIR system for prosecution history
- **Bulk Data**: Available via PatentsView (patentsview.org) with API
- **Search Tips**: Use field codes (TTL/, ABST/, ACLM/) for precision
- **Use**: US-focused patent research, prosecution history, maintenance fee status

### Espacenet (European Patent Office)
- **URL**: worldwide.espacenet.com
- **Coverage**: 140M+ documents from 100+ countries
- **Strengths**: Worldwide coverage, patent family linking, free machine translation
- **Key Features**: Smart search, classification search, Global Dossier access
- **Use**: International patent landscape, European patent research

### WIPO PATENTSCOPE
- **URL**: patentscope.wipo.int
- **Coverage**: 100M+ documents including PCT applications
- **Strengths**: PCT application data, cross-lingual expansion search, CLIR
- **Use**: International patent applications, WIPO statistics

### Lens.org
- **URL**: lens.org
- **Coverage**: 130M+ patent records linked to 200M+ scholarly works
- **Strengths**: Free, links patents to academic literature, biological sequences
- **Key Features**: PatCite links, institutional analysis, bulk export
- **API**: Free API for non-commercial use
- **Use**: Patent-publication linkage, open patent analytics

## Commercial Patent Analytics

### Derwent Innovation (Clarivate)
- Premium patent analytics, enhanced abstracts, prior art search
- **Use**: Professional IP analysis, portfolio management

### PatSnap
- AI-powered patent analytics, landscape visualization, competitive intelligence
- **Use**: Technology scouting, IP strategy, competitive analysis

## Patent Research Best Practices
1. Search across multiple databases - no single source is complete
2. Use CPC/IPC classification codes, not just keywords
3. Search in English AND local languages for international coverage
4. Check patent families (same invention filed in multiple countries)
5. Analyze citation patterns to identify core technologies
6. Use PatentsView API for large-scale quantitative patent analysis
7. Note: filed != granted != commercially viable
8. Patent applications are published ~18 months after filing
