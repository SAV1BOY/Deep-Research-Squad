# Base Rate Neglect in Research

## Definition
Base rate neglect is the tendency to ignore general statistical information (base rates) in favor of specific, case-level information when making probability judgments.

## The Classic Example
- 1% of people have a disease. A test is 99% accurate.
- You test positive. What is the probability you have the disease?
- Most people say ~99%. The correct answer is ~50%.
- Why: Of 1000 people, 10 have it (9 test positive). Of 990 healthy, ~10 false positives. 9/(9+10) = ~47%.

## How It Affects Research

### Startup and Market Assessment
- "This startup has a great team, product, and market" (specific information)
- Base rate: ~90% of startups fail regardless of these factors
- Specific information should adjust the base rate, not replace it
- **Correct approach**: Start at 90% failure rate, then adjust based on specifics

### Competitive Intelligence
- "This company is making aggressive moves that suggest growth"
- Base rate: What percentage of companies in this sector actually achieve high growth?
- Specific signals should modify the base rate, not override it
- **Correct approach**: Start with industry growth rates, then adjust

### Technology Forecasting
- "This technology has breakthrough potential"
- Base rate: What percentage of "breakthrough" technologies achieve mainstream adoption?
- Most "revolutionary" technologies fail or take decades longer than expected
- **Correct approach**: Start with historical adoption rates for similar technologies

### Investment Analysis
- "This company has strong fundamentals"
- Base rate: What percentage of companies with similar metrics actually outperform?
- Individual case details feel compelling but base rates are more predictive
- **Correct approach**: Use reference class forecasting as the baseline

## Why We Neglect Base Rates
1. Specific information is vivid and concrete; base rates are abstract
2. Narratives about individual cases are more engaging than statistics
3. We overweight information we worked hard to obtain
4. Representativeness heuristic: judging by similarity, not probability
5. Illusion of understanding: detailed knowledge creates false confidence

## Reference Class Forecasting
- Developed by Kahneman and Tversky as an antidote to base rate neglect
- Step 1: Identify the appropriate reference class (similar past cases)
- Step 2: Determine the base rate for that class
- Step 3: Adjust based on specific case information (but not too much)
- Key insight: Outside view (reference class) should anchor, inside view (specifics) should adjust

## Debiasing Strategies
1. **Always start with the base rate**: Before any analysis, ask "What usually happens?"
2. **Identify the reference class**: What category does this case belong to?
3. **Anchor on the outside view**: Use statistical base rates as your starting point
4. **Adjust conservatively**: Specific information rarely justifies large deviations
5. **Document your reasoning**: Show the base rate, the adjustment, and the rationale
6. **Use Bayesian updating**: Formally combine base rate with new evidence

## Application to Deep Research
- Begin every analysis with the relevant base rate
- Use reference class forecasting for all predictions
- Present the base rate alongside specific conclusions
- Flag when conclusions deviate significantly from base rates (requires strong justification)
- Build base rate databases for common research domains
- Train yourself to ask "What usually happens?" before "What might happen?"
