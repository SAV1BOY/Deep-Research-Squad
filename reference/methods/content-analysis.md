# Content Analysis

## Overview
Content analysis is a systematic method for analyzing text, images, or other media by categorizing and coding content into defined themes. Can be quantitative (counting occurrences) or qualitative (interpreting meaning). Widely used across social sciences, marketing, and communications research.

## Types of Content Analysis

### Quantitative Content Analysis
- Counts frequency of predefined codes/categories in content
- Emphasizes reliability and replicability
- Statistical analysis of coded data
- **Use**: Large-scale media analysis, trend tracking, sentiment measurement

### Qualitative Content Analysis
- Interprets meaning and context of content
- More flexible coding schemes; categories may emerge from data
- Emphasizes depth of understanding over frequency counts
- **Use**: Understanding narratives, framing, underlying themes

### Directed Content Analysis
- Starts with existing theory or prior research to define initial codes
- Extends or validates a theoretical framework
- Combines deductive (theory-driven) and inductive (data-driven) coding

## Process Steps

### 1. Define Research Questions
- What content to analyze and why
- What patterns or themes are you looking for

### 2. Select Sample
- Define population of content (all articles, specific time period, etc.)
- Sampling strategy (random, stratified, purposive)
- Document inclusion/exclusion criteria

### 3. Develop Coding Scheme
- Define categories and codes with clear definitions
- Create codebook with examples for each code
- Establish coding rules for ambiguous cases

### 4. Pilot Test
- Code a subset independently with multiple coders
- Calculate inter-coder reliability (Cohen's kappa, Krippendorff's alpha)
- Refine codebook based on disagreements

### 5. Code the Content
- Apply coding scheme systematically to all sampled content
- Document coding decisions and edge cases

### 6. Analyze and Report
- Frequency analysis, cross-tabulations, trend analysis
- Interpret patterns in context of research questions

## Reliability Standards
- **Inter-coder reliability**: Cohen's kappa > 0.80 (good), > 0.60 (acceptable)
- **Krippendorff's alpha**: > 0.80 recommended, > 0.667 acceptable for exploratory work
- Must be established before main coding begins

## Application to Deep Research
- Use content analysis to systematically analyze documents, reports, and articles
- Define clear coding categories before analyzing large document sets
- Track frequency of key themes across sources for evidence weighting
- Apply qualitative content analysis for understanding stakeholder positions
- Combine with NLP tools for large-scale automated content analysis
- Document your coding scheme for transparency and reproducibility
