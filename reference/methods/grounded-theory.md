# Grounded Theory

## Overview
Grounded theory is a systematic methodology for constructing theory from data, rather than testing pre-existing hypotheses. Developed by Glaser and Strauss (1967), it builds theory "grounded" in empirical observations through iterative data collection and analysis.

## Core Process

### 1. Open Coding
- Break data into discrete concepts and categories
- Label phenomena observed in the data
- Compare incidents to incidents for similarities and differences
- Generate initial categories from raw data

### 2. Axial Coding
- Relate categories to subcategories
- Identify conditions, strategies, and consequences
- Build connections between categories using paradigm model
- Specify properties and dimensions of each category

### 3. Selective Coding
- Identify the core category that integrates the theory
- Systematically relate core category to other categories
- Validate relationships through data comparison
- Fill in gaps with additional targeted data collection

### 4. Theoretical Sampling
- Data collection guided by emerging theory (not predetermined)
- Seek out cases that test and refine emerging categories
- Continue until theoretical saturation (no new insights emerge)

## Key Concepts
- **Constant comparison**: Continuously compare data with data, data with codes, codes with codes
- **Theoretical sensitivity**: Researcher's ability to recognize important data
- **Memoing**: Written records of theoretical ideas during analysis
- **Theoretical saturation**: Point where additional data yields no new categories

## Three Main Variants
1. **Classic (Glaserian)**: More flexible, discovery-oriented, researcher-driven
2. **Straussian**: More structured, systematic procedures, paradigm model
3. **Constructivist (Charmaz)**: Acknowledges researcher subjectivity, co-constructed meaning

## When to Use
- Exploring new or poorly understood phenomena
- When existing theories are inadequate or absent
- Building frameworks from qualitative data (interviews, documents, observations)
- Understanding processes, interactions, and social phenomena

## Application to Deep Research
- Use open coding approach when analyzing unstructured data from diverse sources
- Apply constant comparison when synthesizing contradictory findings
- Let patterns emerge from data rather than forcing pre-existing frameworks
- Use theoretical sampling: let initial findings guide what to search next
- Document "memos" throughout research process to track emerging insights
- Seek theoretical saturation before concluding research on a topic
