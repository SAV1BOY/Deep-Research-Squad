# Bazzell - OSINT Techniques: Resources for Uncovering Online Information

## OSINT Fundamentals

### What is OSINT?
Open Source Intelligence: collecting and analyzing publicly available information to produce actionable intelligence.

### OSINT Process
1. **Requirements**: Define what you need to find
2. **Collection**: Gather data from open sources
3. **Processing**: Clean, organize, deduplicate
4. **Analysis**: Extract meaning and patterns
5. **Reporting**: Present findings clearly

## Search Engine Techniques

### Google Advanced Search
- `site:domain.com` - Search within a specific site
- `filetype:pdf` - Find specific file types
- `intitle:"keyword"` - Search in page titles
- `inurl:keyword` - Search in URLs
- `"exact phrase"` - Exact match search
- `-keyword` - Exclude terms
- `AROUND(n)` - Terms within n words of each other
- `before:YYYY-MM-DD` / `after:YYYY-MM-DD` - Date range

### Alternative Search Engines
- **DuckDuckGo**: Privacy-focused, different ranking
- **Bing**: Different index, useful for cross-referencing
- **Yandex**: Strong for reverse image search
- **Baidu**: Chinese-language content

## Social Media Intelligence

### LinkedIn
- Company pages reveal employees, growth trends
- Job postings reveal strategy and technology stack
- Employee transitions reveal organizational health
- Skill endorsements map capabilities

### Twitter/X
- Real-time sentiment and reactions
- Employee opinions and complaints
- Customer feedback patterns
- Hashtag analysis for trend tracking

### GitHub/GitLab
- Open source projects reveal technology choices
- Contributor activity shows team size and focus
- Issues and discussions reveal challenges
- Repository activity patterns

## Website Intelligence
- **Wayback Machine** (web.archive.org): Historical website snapshots
- **WHOIS**: Domain registration information
- **DNS records**: Infrastructure details
- **SSL certificates**: Related domains and subdomains
- **robots.txt/sitemap.xml**: Site structure hints
- **Built With / Wappalyzer**: Technology stack identification

## Document and Data Intelligence
- **Google Scholar**: Academic publications by people/orgs
- **Patent databases**: Innovation and R&D direction
- **Court records**: Legal issues and disputes
- **Corporate registries**: Company structure and officers
- **Financial filings**: Revenue, costs, strategy details

## OSINT Workflow Best Practices
1. Document every step for reproducibility
2. Archive findings (pages change or disappear)
3. Verify information through multiple sources
4. Respect legal and ethical boundaries
5. Use separate accounts/profiles for research
6. Maintain operational security
7. Timestamp all collected data

## Application to Deep Research
- Use OSINT techniques as the first layer of any competitive analysis
- Combine search operators for precision (site + filetype + date range)
- Always check Wayback Machine for historical context
- Cross-reference information across multiple platforms
- Document your collection methodology for credibility
- Set up monitoring for ongoing intelligence needs
