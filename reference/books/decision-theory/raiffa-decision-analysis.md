# Raiffa - Decision Analysis: Introductory Lectures on Choices Under Uncertainty

## Decision Analysis Fundamentals

### When to Use Decision Analysis
- Significant consequences from the decision
- Uncertainty about outcomes
- Multiple competing objectives
- Complex trade-offs between options
- Need to communicate reasoning transparently

### Core Components
1. **Alternatives**: What options are available?
2. **Uncertainties**: What do we not know?
3. **Outcomes**: What happens under each scenario?
4. **Preferences**: How do we value different outcomes?

## Decision Trees

### Building a Decision Tree
1. Start with the immediate decision (square node)
2. Branch into available alternatives
3. Add chance nodes (circle) for uncertainties
4. Assign probabilities to each chance branch
5. Add outcomes (payoffs/costs) at terminal nodes
6. Solve by folding back (expected value at each node)

### Key Rules
- Decision nodes: Choose the branch with highest expected value
- Chance nodes: Compute weighted average of branches
- Work backward from outcomes to the initial decision
- Sensitivity analysis: How much do probabilities need to change to flip the decision?

## Expected Value of Information

### Perfect Information (EVPI)
- Maximum you should pay to know the outcome before deciding
- EVPI = EV with perfect info - EV without info
- Upper bound on the value of any research or study

### Imperfect Information
- Most real information is imperfect (not 100% accurate)
- Value depends on how much it reduces uncertainty
- Use Bayes' theorem to update probabilities with new evidence
- Can compute expected value of imperfect information (EVII)

## Multi-Attribute Decision Making

### Weighted Scoring
1. List decision criteria (attributes)
2. Assign weights reflecting importance
3. Score each alternative on each criterion
4. Compute weighted sum for each alternative
5. Sensitivity analysis on weights

### Dominance Analysis
- If option A is better than B on every criterion, A dominates
- Remove dominated options to simplify analysis
- Practical dominance: A is better on most criteria, never much worse

### Trade-off Analysis
- How much of attribute X would you give up for more of attribute Y?
- Makes implicit trade-offs explicit
- Helps identify what really matters in the decision

## Dealing with Risk

### Risk Attitude
- **Risk neutral**: Cares only about expected value
- **Risk averse**: Prefers certain outcomes over gambles with same EV
- **Risk seeking**: Prefers gambles over certain outcomes with same EV
- Most decision makers are risk averse for losses, risk seeking for gains

### Sensitivity Analysis
- Vary key inputs one at a time (tornado diagram)
- Identify which variables have the most impact on the decision
- Focus research effort on reducing uncertainty in high-impact variables

## Application to Deep Research
- Frame research questions as decision problems when possible
- Build simple decision trees for key strategic choices
- Calculate information value before recommending additional research
- Use multi-attribute analysis for comparing complex alternatives
- Make trade-offs explicit rather than implicit
- Sensitivity analysis reveals which assumptions matter most
- Present uncertainty ranges, not just best estimates
