# Saldana - The Coding Manual for Qualitative Researchers

## What Is Qualitative Coding?
A code is a word or short phrase that symbolically assigns a summative, salient, essence-capturing attribute to a portion of language-based or visual data.

## First Cycle Coding Methods

### Grammatical Methods
- **Attribute coding**: Log descriptive info (participant, date, setting)
- **Magnitude coding**: Add intensity/frequency to codes (HIGH, LOW)

### Elemental Methods
- **Structural coding**: Label data segments by research question
- **Descriptive coding**: Summarize topic of a passage in a word/phrase
- **In Vivo coding**: Use participants' own words as codes
- **Process coding**: Use gerunds to capture action (-ing words)

### Affective Methods
- **Emotion coding**: Label emotions recalled or experienced
- **Values coding**: Code for values, attitudes, and beliefs
- **Evaluation coding**: Assign judgments about merit or worth

### Literary and Language Methods
- **Dramaturgical coding**: Code for objectives, conflicts, tactics
- **Motif coding**: Identify recurring elements or patterns

### Exploratory Methods
- **Holistic coding**: Apply a single code to large units of data
- **Provisional coding**: Start with a pre-determined list, then refine

### Procedural Methods
- **Protocol coding**: Use pre-established coding systems
- **Outline of Cultural Materials (OCM)**: Ethnographic categories

## Second Cycle Coding Methods
- **Pattern coding**: Group first-cycle codes into themes/categories
- **Focused coding**: Search for most frequent or significant codes
- **Axial coding**: Relate categories to subcategories (conditions, strategies, consequences)
- **Theoretical coding**: Integrate categories into a theory
- **Elaborative coding**: Refine existing theoretical framework with new data

## The Coding Process
1. Read through all data first (pre-coding: highlight, note)
2. First cycle: Apply initial codes (expect 80-100+ codes)
3. Organize codes into categories
4. Second cycle: Consolidate into themes/patterns (15-20 categories)
5. Develop assertions or theory from themes

## Code Organization Tools
- **Code book**: Master list with definitions and examples
- **Code maps**: Visual display of code relationships
- **Code frequency tables**: Which codes appear most
- **Code co-occurrence**: Which codes appear together

## Quality Checks
- Inter-coder reliability: Multiple coders, compare agreement
- Member checking: Verify codes with participants
- Audit trail: Document coding decisions
- Negative case analysis: Look for data that contradicts codes

## Application to Deep Research
- Use descriptive coding for initial document analysis
- Use In Vivo coding to preserve original language from sources
- Process coding works well for analyzing workflows and strategies
- Pattern coding helps synthesize across multiple sources
- Always maintain a codebook for consistency across large research projects
- Second cycle coding is where synthesis and insight emerge
