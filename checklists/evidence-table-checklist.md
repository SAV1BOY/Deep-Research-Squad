# Evidence Table Quality Checklist

## Purpose
Ensure that evidence tables are complete, well-structured, and provide a reliable foundation for analysis and conclusions. Evidence tables are the backbone of rigorous research, and this checklist validates that each table systematically catalogs, evaluates, and organizes evidence for transparent decision-making.

## When to Use
- Before incorporating an evidence table into any research deliverable
- When reviewing evidence tables prepared by team members
- During the evidence synthesis phase of any research project
- When evidence tables will be used to support thesis testing or due diligence

## Prerequisites
- Research question or thesis that the evidence supports is clearly defined
- Source collection phase is complete or substantially complete
- Source quality assessment criteria have been established
- Evidence categorization schema has been agreed upon
- Template or format for the evidence table has been selected

## Checklist Items

### Section 1: Structure and Format
1. [ ] Evidence table follows the agreed-upon template or format — PASS: template compliance; FAIL: non-standard format without justification
2. [ ] Each row represents a single, discrete piece of evidence — PASS: atomic entries; FAIL: compound entries mixing multiple claims
3. [ ] Columns include at minimum: source, claim, evidence type, quality rating, relevance — PASS: minimum columns present; FAIL: essential columns missing
4. [ ] Table is sortable and filterable by key columns — PASS: structured for analysis; FAIL: flat text format only
5. [ ] Unique identifier is assigned to each evidence entry — PASS: IDs present; FAIL: no identification system

### Section 2: Completeness
6. [ ] All relevant sources identified during research are represented — PASS: comprehensive coverage; FAIL: sources missing from table
7. [ ] Both supporting and contradicting evidence is included — PASS: balanced representation; FAIL: one-sided evidence collection
8. [ ] Each evidence entry includes direct quotes or specific data points — PASS: specific evidence cited; FAIL: vague references
9. [ ] Page numbers, section references, or URLs are provided for each entry — PASS: locatable evidence; FAIL: untraceable references
10. [ ] Gaps in evidence coverage are identified and noted — PASS: gaps flagged; FAIL: gaps not acknowledged

### Section 3: Quality Assessment
11. [ ] Each piece of evidence has a quality rating (high, medium, low) — PASS: all entries rated; FAIL: unrated entries
12. [ ] Quality rating criteria are defined and consistently applied — PASS: consistent methodology; FAIL: inconsistent or undefined criteria
13. [ ] Source credibility is factored into evidence quality — PASS: source quality considered; FAIL: evidence quality assessed without source context
14. [ ] Corroboration status is noted (corroborated, uncorroborated, contradicted) — PASS: corroboration tracked; FAIL: no corroboration assessment
15. [ ] Recency and timeliness of evidence is evaluated — PASS: temporal relevance assessed; FAIL: undated evidence accepted

### Section 4: Analysis Support
16. [ ] Evidence is categorized by theme or sub-question — PASS: thematic organization; FAIL: uncategorized entries
17. [ ] Weight or significance is assigned to key evidence — PASS: importance differentiated; FAIL: all evidence treated as equally significant
18. [ ] Contradictions between evidence entries are flagged — PASS: conflicts highlighted; FAIL: contradictions not identified
19. [ ] Evidence chain from source to claim to conclusion is traceable — PASS: full chain documented; FAIL: logical gaps in evidence chain
20. [ ] Summary statistics on evidence distribution are provided — PASS: counts by category, quality, and type; FAIL: no aggregate view

### Section 5: Documentation and Maintenance
21. [ ] Date of last update is recorded — PASS: date present; FAIL: undated table
22. [ ] Author or maintainer is identified — PASS: ownership clear; FAIL: anonymous table
23. [ ] Version history is maintained for significant updates — PASS: versioning in place; FAIL: no change tracking
24. [ ] Instructions for reading and using the table are provided — PASS: usage guide included; FAIL: no instructions for consumers
25. [ ] Table is cross-referenced to the research deliverable it supports — PASS: linked to parent deliverable; FAIL: orphaned table

## Scoring
- Count the total number of items marked PASS
- Quality Score = (PASS count / 25) x 100
- Grade thresholds:
  - 92-100%: Excellent — rigorous and comprehensive evidence foundation
  - 80-91%: Good — solid evidence base with minor gaps
  - 68-79%: Acceptable — usable but should be strengthened
  - Below 68%: Insufficient — evidence table cannot reliably support conclusions

## Escalation
- **Accept**: Score of 80% or above with no FAIL on items 3, 7, 11, or 18
- **Revise**: Score of 68-79%, or any FAIL on items 3, 7, 11, or 18
- **Escalate to lead**: Score below 68%, or systematic quality concerns identified, or evidence table reveals that research scope was insufficient
- **Escalate to stakeholder**: Evidence table reveals that the research question cannot be adequately answered with available evidence, requiring scope or approach changes
