# Timeline Causality Check

## Purpose

Evaluate whether causal claims derived from the timeline are supported by
evidence and not merely based on temporal sequence. "After" does not mean
"because of" -- this gate guards against post-hoc reasoning.

## Gate Question

**Are causal inferences from the timeline supported by evidence, not just
temporal sequence?**

## Prerequisites

- Timeline constructed and completeness gate passed.
- Causal claims identified in the research.
- Evidence for causal mechanisms collected.
- Alternative explanations considered.

## Pass Criteria

1. Every causal claim identifies both the cause event and the effect event
   on the timeline.
2. A plausible causal mechanism is described (not just "A happened before B").
3. The time lag between cause and effect is consistent with the proposed
   mechanism.
4. Alternative causes for the same effect are considered and addressed.
5. Confounding events occurring in the same period are identified.
6. Reverse causality is considered (could the effect have caused the cause?).
7. Post-hoc-ergo-propter-hoc reasoning is explicitly guarded against.

## Fail Actions

- If causal mechanism is missing: research the mechanism or downgrade to
  correlation.
- If alternative causes are not considered: identify at least 2 alternatives.
- If confounders are not identified: review the timeline for co-occurring
  events.
- If reverse causality is not addressed: assess its plausibility.
- If post-hoc reasoning is present: rewrite the claim as correlation with
  appropriate caveats.

## Escalation Rules

- Escalate if causal claims are central to the conclusion but evidence for
  mechanism is weak.
- Escalate if domain expertise is needed to assess causal plausibility.
- Escalate if the causal analysis reveals the research question itself
  contains an embedded causal assumption that may be false.
