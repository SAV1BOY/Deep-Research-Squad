# Timeline Completeness Gate

## Purpose

Ensure the constructed timeline captures all significant events relevant to
the research question. An incomplete timeline leads to gaps in causal
reasoning and missed turning points.

## Gate Question

**Does the timeline include all significant events within the scope?**

## Prerequisites

- Temporal boundaries defined in the scope.
- Events collected from multiple sources.
- Key entities and their roles over time identified.
- Chronological ordering applied.

## Pass Criteria

1. All events cited in the evidence base are placed on the timeline.
2. Start and end dates match the scope's temporal boundaries.
3. No gaps longer than the expected event frequency exist without
   explanation (e.g., no unexplained 5-year gap in an annual event series).
4. Events from all relevant source classes are included (not just one
   source type's perspective).
5. Both public and less-reported events are captured (not just headlines).
6. Dates are precise to the appropriate resolution (day, month, year).
7. Each event has a brief description and source citation.

## Fail Actions

- If events are missing: search for events in the identified gaps.
- If temporal boundaries are not respected: trim or extend as needed.
- If unexplained gaps exist: investigate whether events occurred or
  document that the gap is genuine.
- If date precision is inconsistent: standardize to the best available
  precision.
- If events lack citations: add source references.

## Escalation Rules

- Escalate if the timeline reveals events that were unknown to the
  research team and change the analysis.
- Escalate if critical events cannot be dated with sufficient precision.
- Escalate if competing timelines from different sources cannot be
  reconciled.
