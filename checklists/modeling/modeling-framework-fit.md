# Modeling Framework Fit Check

## Purpose

Verify that the chosen analytical framework or model is appropriate for the
problem at hand. A mismatched framework produces structured but misleading
analysis.

## Gate Question

**Is the selected framework the right fit for this problem?**

## Prerequisites

- Problem type classified (strategic, operational, predictive, evaluative).
- Candidate frameworks identified (SWOT, Porter's Five Forces, PESTEL,
  system dynamics, decision trees, etc.).
- Data availability assessed.
- Desired output type defined (ranking, scenario, map, score).

## Pass Criteria

1. The framework's assumptions match the problem's characteristics.
2. The framework's inputs can be populated with available data.
3. The framework produces the type of output the requester needs.
4. The framework handles the problem's complexity level (not too simple,
   not too complex).
5. The framework is well-established in the relevant domain.
6. Limitations of the framework are documented and acceptable.
7. An alternative framework was considered and the selection rationale
   is documented.

## Fail Actions

- If assumptions do not match: select a different framework or modify
  the current one.
- If inputs cannot be populated: simplify the framework or source
  additional data.
- If output type is wrong: switch to a framework that produces the
  needed output.
- If framework limitations are not documented: add them.
- If no alternative was considered: evaluate at least one alternative.

## Escalation Rules

- Escalate if no standard framework fits the problem and a custom model
  needs to be designed.
- Escalate if the framework selection is contested among agents.
- Escalate if the chosen framework requires quantitative inputs that
  exceed the agents' analytical capability.
