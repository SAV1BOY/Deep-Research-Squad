# Source Diversity Gate

## Purpose

Ensure that critical claims are supported by multiple independent source
classes, preventing over-reliance on any single type of evidence. Source
diversity strengthens confidence in findings.

## Gate Question

**Are at least 3 source classes represented per critical claim?**

## Prerequisites

- Critical claims identified and listed.
- Source collection phase completed or substantially underway.
- Source classification taxonomy defined (academic, news, government,
  industry, primary data, expert, legal, social media).
- Source inventory accessible.

## Pass Criteria

1. Each critical claim is supported by sources from >= 3 distinct classes.
2. No single source class accounts for more than 50% of total citations.
3. At least one source per critical claim is from a non-web medium (books,
   reports, datasets, interviews) when feasible.
4. Source classes include both structured (data, reports) and unstructured
   (commentary, analysis) types.
5. Geographic diversity in sources mirrors the geographic scope.
6. Institutional diversity is present (government, private sector, NGO,
   academic).
7. Source diversity is documented in the source inventory table.

## Fail Actions

- If fewer than 3 classes per critical claim: search for additional source
  types before concluding.
- If one class dominates: deliberately seek underrepresented classes.
- If geographic diversity is lacking: add sources from relevant regions.
- If only web sources used: attempt to find reports, books, or datasets.
- If diversity is undocumented: build the source inventory table.

## Escalation Rules

- Escalate if the topic is so niche that 3 source classes genuinely do
  not exist.
- Escalate if achieving diversity would require purchasing access to
  expensive databases.
- Escalate if source diversity reveals contradictions that cannot be
  resolved without domain expertise.
