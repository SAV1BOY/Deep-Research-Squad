# Source Independence Gate

## Purpose

Verify that sources are genuinely independent and not circular (multiple
sources all deriving from the same original). Circular sourcing creates
false confidence by making one piece of evidence appear as many.

## Gate Question

**Are the sources independent of each other, not circular?**

## Prerequisites

- Source inventory with full bibliographic details.
- Citation chains traced for key claims.
- Original/primary sources identified where possible.
- Author and publisher relationships mapped.

## Pass Criteria

1. No two sources for the same claim originate from a single primary source
   without that primary source being cited directly.
2. Wire service / press release duplication is identified and collapsed
   (count as one source, not many).
3. Sources do not share authors, editors, or funding bodies in ways that
   compromise independence.
4. Wikipedia and other aggregators are traced to their underlying references.
5. Secondary sources that cite each other are identified as a cluster,
   not as independent confirmations.
6. At least 2 genuinely independent evidence paths exist for each critical
   claim.
7. Independence assessment is documented per claim.

## Fail Actions

- If circular sourcing detected: trace back to the original and cite it
  directly; remove illusory confirmations.
- If wire service duplication found: consolidate to one source entry.
- If shared funding/authorship creates dependency: note the relationship
  and seek a truly independent source.
- If Wikipedia is cited: replace with its underlying references.
- If fewer than 2 independent paths for a critical claim: search for
  additional independent evidence.

## Escalation Rules

- Escalate if all available sources trace back to a single original and
  no independent confirmation can be found.
- Escalate if institutional relationships between sources are opaque and
  cannot be determined.
- Escalate if circular sourcing is discovered after synthesis, requiring
  a confidence downgrade in findings.
