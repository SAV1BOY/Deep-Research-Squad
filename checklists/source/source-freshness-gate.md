# Source Freshness Gate

## Purpose

Verify that sources are sufficiently current for the research topic.
Outdated sources can lead to conclusions that no longer reflect reality,
especially in fast-moving domains.

## Gate Question

**Are the sources up to date relative to the topic's rate of change?**

## Prerequisites

- Sources collected and catalogued with publication dates.
- Topic's rate of change classified (fast-moving, moderate, stable).
- Freshness targets defined in the source plan.
- Any known recent developments in the field identified.

## Pass Criteria

1. Freshness target is defined (e.g., within 2 years for tech, 5 years
   for social science, 10 years for historical analysis).
2. At least 50% of sources meet the freshness target.
3. The most recent source is from within the last 12 months for
   fast-moving topics.
4. Older sources are included only when they are seminal works or provide
   historical context explicitly needed.
5. Sources predating a known paradigm shift are flagged as potentially
   outdated.
6. No critical claim rests solely on a source older than the freshness
   target.
7. Date of each source is recorded in the source inventory.

## Fail Actions

- If freshness target not defined: set one based on topic change rate.
- If fewer than 50% meet the target: conduct additional searches filtered
  by date.
- If a critical claim rests on stale sources: actively search for newer
  evidence.
- If a paradigm shift is known: verify all pre-shift sources against
  post-shift evidence.
- If dates are missing from sources: investigate and add them.

## Escalation Rules

- Escalate if the topic is so new that almost no sources exist yet.
- Escalate if freshness requirements conflict with source diversity goals
  (only one source type has recent data).
- Escalate if a critical source's date cannot be determined.
