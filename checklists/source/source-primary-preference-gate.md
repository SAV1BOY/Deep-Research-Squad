# Source Primary Preference Gate

## Purpose

Ensure that primary sources (original data, official records, firsthand
accounts) are prioritized over secondary and tertiary sources. Primary
sources reduce interpretation layers and increase evidence reliability.

## Gate Question

**Are primary sources prioritized over secondary and tertiary sources?**

## Prerequisites

- Source inventory classified by source order (primary, secondary, tertiary).
- Definition of "primary" established for the domain (e.g., original
  research, raw data, legal filings, firsthand testimony).
- Source plan specifies primary source targets.
- Access constraints for primary sources assessed.

## Pass Criteria

1. At least 30% of sources used for critical claims are primary.
2. When a secondary source is used, an attempt to locate the primary
   source it references has been made.
3. Primary sources are cited directly, not through a secondary's
   paraphrase.
4. Raw data is used in preference to others' analysis of that data
   when feasible.
5. Official documents (legislation, filings, standards) are sourced
   from the issuing body, not intermediaries.
6. Firsthand accounts are preferred over retellings.
7. Reasons for not using primary sources are documented per claim.

## Fail Actions

- If primary source ratio is below 30%: conduct targeted searches for
  primary evidence.
- If secondary sources paraphrase without citation to primary: trace
  back and cite the original.
- If raw data exists but was not used: obtain and reference it.
- If official documents were sourced from intermediaries: locate the
  original issuing body's version.
- If primary source is inaccessible: document the barrier and use the
  best available secondary with a caveat.

## Escalation Rules

- Escalate if primary sources are behind paywalls, classified, or
  restricted and no workaround is available.
- Escalate if primary sources exist but are in a language or format
  the agents cannot process.
- Escalate if the distinction between primary and secondary is unclear
  for the domain and expert judgment is needed.
