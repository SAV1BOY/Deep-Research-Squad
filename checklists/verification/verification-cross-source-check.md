# Verification Cross-Source Check

## Purpose

Systematically verify claims by checking them against multiple independent
sources. Cross-source verification is the primary mechanism for catching
errors, bias, and fabrication.

## Gate Question

**Has each critical claim been verified against independent sources?**

## Prerequisites

- Critical claims identified and listed.
- At least 2 independent sources available per critical claim.
- Source independence verified (not circular).
- Verification log template ready.

## Pass Criteria

1. Every critical claim has been checked against at least 2 independent
   sources.
2. Verification results are logged: confirmed, partially confirmed,
   contradicted, or unverifiable.
3. Confirmed claims note which sources agree and on what specific points.
4. Partially confirmed claims specify which elements are verified and
   which are not.
5. Contradicted claims are routed to the conflict resolution process.
6. Unverifiable claims are labeled as such with explanation of why
   verification failed.
7. Cross-source check coverage is >= 90% for critical claims.

## Fail Actions

- If a critical claim has fewer than 2 independent source checks: find
  additional sources.
- If verification is not logged: complete the verification log.
- If contradicted claims are not routed to conflict resolution: route
  them immediately.
- If coverage is below 90%: prioritize unchecked critical claims.
- If sources cannot be found for verification: document the claim as
  single-source with reduced confidence.

## Escalation Rules

- Escalate if cross-source checking reveals systematic inaccuracies in
  a primary source.
- Escalate if a critical claim cannot be verified by any independent
  source.
- Escalate if verification contradicts a claim that has already been
  delivered in an interim report.
