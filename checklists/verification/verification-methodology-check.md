# Verification Methodology Check

## Purpose

Evaluate whether the methodology used in source studies and data collection
is sound. Evidence from flawed methodologies should be downweighted or
excluded from conclusions.

## Gate Question

**Is the methodology behind key evidence sources sound and appropriate?**

## Prerequisites

- Key evidence sources identified with their methodological descriptions.
- Domain standards for acceptable methodology known.
- Sample sizes, study designs, and analytical methods documented where
  available.
- Statistical literacy sufficient for the domain.

## Pass Criteria

1. Study design is appropriate for the conclusions drawn (e.g., no causal
   claims from correlational studies without caveat).
2. Sample sizes are adequate for the claims made.
3. Selection bias, survivorship bias, and confounding variables are
   addressed or acknowledged.
4. Data collection methods are transparent and replicable.
5. Statistical methods (if used) are appropriate for the data type.
6. Limitations are disclosed by the source authors.
7. Peer review or equivalent quality control was applied to the source.

## Fail Actions

- If methodology is inappropriate for the claims: downweight the evidence
  and note the methodological mismatch.
- If sample sizes are inadequate: flag the limitation and seek larger
  studies.
- If bias is unaddressed: note the specific bias risk and adjust
  confidence accordingly.
- If methods are opaque: reduce trust in the source and seek transparent
  alternatives.
- If no peer review: treat the source as preliminary evidence only.

## Escalation Rules

- Escalate if a critical claim rests on evidence with known methodological
  flaws and no alternative evidence exists.
- Escalate if methodological assessment requires specialist expertise
  (e.g., advanced statistics, clinical trial design).
- Escalate if methodology evaluation reveals that a major source should
  be excluded, significantly changing the conclusion.
