# Cross-Source Verification Gate

## Purpose

Verify that key claims are corroborated by multiple independent sources
before they are accepted as findings. Single-source claims carry higher risk
of error, bias, or fabrication and must be flagged or corroborated.

## When Triggered

- After initial evidence collection for each research sub-question.
- Before claims are promoted from "candidate" to "finding" status.
- When a high-impact claim rests on a single source.

## Prerequisites

- Claims extracted and catalogued with source attributions.
- Source independence assessed (no shared origin or circular reporting).
- Source trust ratings assigned.

## Checklist

- [ ] Each key claim is supported by at least two independent sources.
- [ ] Sources corroborating a claim are verified as truly independent (not circular reporting).
- [ ] Discrepancies between sources on the same claim are documented with details.
- [ ] Claims supported by only one source are explicitly flagged with reduced confidence.
- [ ] Source types are varied for corroboration (e.g., not all media reports from the same wire service).
- [ ] Primary sources are preferred over secondary or tertiary sources for verification.
- [ ] Corroborating sources cover different aspects of the claim (who, what, when, where, why).
- [ ] Time proximity of sources is assessed (independent reports vs. cascade from one break).
- [ ] Known biases of corroborating sources are in opposing directions (not all biased the same way).
- [ ] Any claim that cannot be cross-verified is assigned an appropriate uncertainty qualifier.

## Pass / Fail Criteria

**Pass**: All key claims are corroborated by at least two independent sources,
or single-source claims are flagged with reduced confidence and explicit
uncertainty qualifiers.

**Fail**: Key claims lack corroboration and are not flagged, or source
independence has not been verified.

## Escalation if Failed

- Return uncorroborated claims to the Discovery squad for additional source
  identification.
- If corroboration is impossible, downgrade the claim's confidence level in
  all downstream outputs.
- Escalate to the Contrarian squad if an uncorroborated claim is central to
  the thesis.
- Document verification gaps in the research quality scorecard.
