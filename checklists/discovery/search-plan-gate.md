# Search Plan Gate

## Purpose

This gate ensures that the search plan is comprehensive, systematic, and
aligned with the defined problem and scope before evidence gathering begins.
A weak search plan produces biased or incomplete evidence bases, leading to
conclusions that do not withstand scrutiny. This gate enforces rigor in
how research teams approach information discovery.

## Gate Question

**Is the search plan comprehensive?**

The search plan must cover all relevant source types, employ multiple
search strategies to reduce blind spots, and include mechanisms for
discovering information the team does not yet know to look for.

## Pass Criteria

1. The search plan maps each sub-question to specific search strategies and source types.
2. Multiple independent search paths are defined to reduce single-source dependency.
3. Primary sources are prioritized over secondary and tertiary sources where available.
4. Both confirming and disconfirming evidence strategies are included to avoid confirmation bias.
5. Source diversity requirements are set across author, institution, geography, and perspective.
6. Search terms and queries are documented with planned variations and synonyms.
7. A discovery protocol exists for following leads found during initial searches.
8. Stop criteria are defined so the team knows when sufficient evidence has been gathered.
9. Known data gaps are identified with contingency plans for each.
10. The plan includes a timeline with milestones for progress checkpoints.
11. Roles and responsibilities are assigned for each search track.
12. The search plan has been reviewed for blind spots by someone not involved in framing.
13. Quality filters are predefined for initial source screening.

## Fail Actions

- If only one search strategy exists, add at least two alternative approaches.
- If disconfirming evidence strategies are absent, add explicit searches for counter-evidence.
- If source diversity is insufficient, identify underrepresented perspectives and add search paths.
- If stop criteria are missing, define minimum evidence thresholds per sub-question.
- If no discovery protocol exists, create guidelines for when and how to follow emerging leads.
- If the plan has not been peer-reviewed, assign a reviewer before proceeding.
- If known data gaps lack contingency plans, document the risk and propose mitigations.
- If the timeline is unrealistic given the scope, negotiate scope reduction or timeline extension.
- Record all search plan revisions with rationale in the research log.
- Do not begin evidence gathering until the search plan passes this gate.
