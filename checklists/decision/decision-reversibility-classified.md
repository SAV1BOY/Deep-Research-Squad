# Decision Reversibility Classified Check

## Purpose

Classify each decision option by its reversibility. Irreversible decisions
require higher confidence and more careful analysis than easily reversible
ones. This distinction directly affects the appropriate decision speed.

## Gate Question

**Is each option classified by its reversibility and consequences?**

## Prerequisites

- Decision options documented.
- Consequences of each option analyzed.
- Time horizon for consequences understood.
- Ability to undo or modify each decision assessed.

## Pass Criteria

1. Each option is classified as reversible, partially reversible, or
   irreversible.
2. The cost of reversal is estimated (time, money, reputation).
3. The time window for reversal is stated (hours, months, never).
4. Irreversible options are flagged for extra scrutiny and higher
   evidence thresholds.
5. Reversible options are identified as candidates for experimentation
   or phased rollout.
6. Lock-in effects are identified (when does a reversible choice become
   irreversible).
7. Reversibility classification influences the recommended decision
   approach (fast for reversible, deliberate for irreversible).

## Fail Actions

- If reversibility is not classified: assess each option against the
  reversibility criteria.
- If cost of reversal is unknown: estimate or flag as uncertain.
- If irreversible options lack extra scrutiny: apply higher evidence
  thresholds.
- If lock-in effects are unidentified: analyze decision timelines for
  points of no return.
- If reversibility does not influence the recommendation: adjust the
  recommendation approach.

## Escalation Rules

- Escalate if a decision is irreversible and the evidence confidence is
  below the threshold for such decisions.
- Escalate if the reversibility of a critical option cannot be determined.
- Escalate if the requester is moving quickly on an irreversible decision
  and the analysis suggests caution.
