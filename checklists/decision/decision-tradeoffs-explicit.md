# Decision Trade-offs Explicit Check

## Purpose

Ensure that the trade-offs between decision options are clearly articulated.
Hidden trade-offs lead to surprise consequences and erode trust in the
research output.

## Gate Question

**Are the trade-offs between options explicitly stated?**

## Prerequisites

- Decision options identified and documented.
- Evaluation criteria defined (cost, speed, risk, quality, etc.).
- Evidence base for each option's pros and cons assembled.
- Stakeholder priorities understood.

## Pass Criteria

1. Each option is evaluated against the same set of criteria.
2. Pros and cons for each option are stated with supporting evidence.
3. Trade-offs between criteria are explicit (e.g., "Option A is faster
   but more expensive than Option B").
4. Quantitative trade-offs are quantified where possible.
5. Qualitative trade-offs are described in concrete terms, not vague
   language.
6. Second-order consequences are considered (what happens downstream).
7. A comparison matrix or table summarizes all trade-offs.

## Fail Actions

- If evaluation criteria are inconsistent across options: standardize.
- If trade-offs are implicit: make them explicit in a comparison table.
- If quantification is missing where data exists: add the numbers.
- If second-order consequences are not considered: analyze at least one
  per option.
- If comparison matrix is absent: create one.

## Escalation Rules

- Escalate if the trade-offs reveal that no option is clearly superior
  and the decision is genuinely difficult.
- Escalate if trade-off analysis requires cost or impact estimates beyond
  the agents' capability.
- Escalate if stakeholder priorities are unknown and trade-off weighting
  cannot be determined.
