# Decision Options Complete Check

## Purpose

Ensure all viable decision options have been identified before evaluation
begins. Missing a viable option can lead to suboptimal decisions even if the
analysis of presented options is flawless.

## Gate Question

**Have all viable decision options been identified and documented?**

## Prerequisites

- Research findings and synthesis completed.
- Decision context understood (what choice the requester faces).
- Constraints on feasible options identified (budget, time, legal, etc.).
- Stakeholder preferences surveyed.

## Pass Criteria

1. At least 3 distinct options are presented (including status quo / do
   nothing).
2. Options span a range of ambition levels (conservative, moderate, bold).
3. Each option is feasible given the known constraints.
4. Hybrid or phased options are considered where appropriate.
5. Options are mutually exclusive or explicitly noted as combinable.
6. No viable option was excluded without documented justification.
7. The option set was reviewed against common frameworks (e.g., build vs.
   buy vs. partner) to catch missing categories.

## Fail Actions

- If fewer than 3 options: generate additional alternatives including
  unconventional ones.
- If status quo is missing: add it as the baseline option.
- If options are all similar: diversify by varying key dimensions.
- If an option was excluded without justification: restore it or document
  the reason.
- If no framework check was done: apply at least one option-generation
  framework.

## Escalation Rules

- Escalate if the requester has pre-committed to an option and will not
  consider alternatives despite the analysis suggesting otherwise.
- Escalate if generating viable options requires domain expertise the
  agents lack.
- Escalate if all identified options have significant drawbacks and the
  requester expects a clearly superior choice.
