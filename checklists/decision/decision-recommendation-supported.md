# Decision Recommendation Supported Check

## Purpose

Ensure that the final recommendation is fully supported by the research
evidence and analysis. A recommendation that goes beyond the evidence
undermines the entire research process.

## Gate Question

**Is the recommendation fully supported by evidence and analysis?**

## Prerequisites

- All decision gates passed (options, trade-offs, risks, reversibility).
- Evidence base with confidence scores available.
- Synthesis completed and reviewed.
- Stakeholder context and priorities understood.

## Pass Criteria

1. The recommendation explicitly links to supporting evidence.
2. The recommendation is consistent with the confidence levels assigned
   to the underlying findings.
3. The recommendation accounts for the trade-offs and explains why they
   are acceptable.
4. The recommendation addresses the top risks and includes or references
   mitigations.
5. The recommendation respects the reversibility classification (cautious
   for irreversible decisions).
6. Alternative options are acknowledged and reasons for not recommending
   them are stated.
7. Conditions under which the recommendation should be revisited are
   specified.

## Fail Actions

- If evidence links are missing: add explicit citations from the evidence
  base.
- If recommendation exceeds evidence confidence: qualify the recommendation
  or strengthen the evidence.
- If trade-offs are not addressed: add the trade-off rationale.
- If risks are ignored: incorporate risk considerations.
- If revision conditions are missing: define the triggers for revisiting
  the recommendation.

## Escalation Rules

- Escalate if the evidence does not support any recommendation and the
  output must acknowledge this.
- Escalate if the recommendation conflicts with the requester's stated
  preferences and the conflict should be surfaced.
- Escalate if implementing the recommendation requires actions outside
  the requester's control.
- Escalate if the agents disagree on the recommendation.
