# Scope Sub-Question Completeness Gate

## Purpose

Verify that the set of sub-questions fully covers the research topic so that
answering all of them would constitute a complete answer to the original
question.

## Gate Question

**Do the sub-questions collectively cover the entire topic?**

## Prerequisites

- Core research question framed and approved.
- Initial decomposition into sub-questions completed.
- Boundaries defined and documented.
- Requester's priorities among dimensions known.

## Pass Criteria

1. Sub-questions span all major dimensions of the core question.
2. No obvious angle is missing that a domain expert would expect.
3. Sub-questions include both descriptive ("what") and analytical ("why/how")
   components where appropriate.
4. Sub-questions address stakeholder perspectives if the topic is contested.
5. At least one sub-question targets limitations, risks, or counter-arguments.
6. The set is between 3 and 12 sub-questions (manageable yet thorough).
7. Each sub-question is independently answerable (not redundant or circular).

## Fail Actions

- If a major dimension is missing: add the sub-question and update the
  scope document.
- If sub-questions exceed 12: merge related ones or defer lower-priority
  items to a follow-up phase.
- If fewer than 3: the decomposition is too shallow; expand.
- If redundancy exists: merge overlapping sub-questions.
- If no contrarian sub-question exists: add one addressing risks or
  counter-arguments.

## Escalation Rules

- Escalate if domain expertise is needed to assess completeness and no
  agent has sufficient knowledge.
- Escalate if the requester adds new sub-questions that change the scope
  after approval.
- Escalate if the sub-question count drives the research beyond the
  allocated time budget.
