# Synthesis Layers Complete Check

## Purpose

Verify that all research layers have submitted their outputs and that the
synthesis has material from every planned investigation stream. Incomplete
input produces incomplete synthesis.

## Gate Question

**Have all research layers delivered their outputs for synthesis?**

## Prerequisites

- Research design with layer assignments available.
- Layer completion status tracked.
- Expected output format and content per layer defined.
- Deadline for layer submissions set.

## Pass Criteria

1. Every assigned layer has submitted its output.
2. Each submission meets the expected format and minimum content
   requirements.
3. No layer output is marked as "placeholder" or "draft" without a
   completion plan.
4. Late submissions are received or a documented decision exists to
   proceed without them.
5. Layer outputs collectively cover all sub-questions.
6. Cross-references between layers are present where the research design
   specified them.
7. A completeness matrix maps layers to sub-questions with a status
   for each cell.

## Fail Actions

- If a layer has not submitted: contact the responsible agent and set
  a final deadline.
- If a submission is below minimum content: return it for completion.
- If proceeding without a layer: document what is missing and its impact
  on the synthesis.
- If cross-references are absent: request them from the relevant agents.
- If the completeness matrix has gaps: assess whether synthesis can
  proceed or must wait.

## Escalation Rules

- Escalate if a critical layer is missing and cannot be completed in
  time.
- Escalate if more than 20% of layers are incomplete at synthesis start.
- Escalate if a layer's output is so poor that it cannot be used and
  must be redone.
