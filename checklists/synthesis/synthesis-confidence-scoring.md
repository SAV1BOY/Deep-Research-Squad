# Synthesis Confidence Scoring Check

## Purpose

Ensure every major finding and conclusion has an explicit confidence score
that reflects the strength, consistency, and completeness of the underlying
evidence. Confidence scores enable informed decision-making.

## Gate Question

**Does every major finding have an appropriate confidence score?**

## Prerequisites

- Evidence strength ratings completed.
- Evidence consistency assessment completed.
- Evidence completeness assessment completed.
- Confidence scoring rubric defined (e.g., high/medium/low or numerical).

## Pass Criteria

1. Every major finding has an explicit confidence score.
2. Confidence scores are based on defined criteria (not gut feel).
3. The criteria include: evidence strength, source diversity, consistency,
   completeness, and recency.
4. High confidence requires strong evidence from multiple independent
   sources with no unresolved conflicts.
5. Medium confidence is assigned when evidence is moderate or incomplete.
6. Low confidence is assigned when evidence is weak, contradictory, or
   from single sources.
7. Confidence scores are presented alongside findings, not buried in
   footnotes.

## Fail Actions

- If confidence scores are missing: assign them using the rubric.
- If scores are not criteria-based: apply the scoring rubric retroactively.
- If high confidence is assigned to weakly supported claims: downgrade.
- If confidence presentation is poor: move scores to be adjacent to
  each finding.
- If the scoring rubric was not defined: define it and apply consistently.

## Escalation Rules

- Escalate if the requester expects high confidence but the evidence
  only supports low or medium.
- Escalate if agents disagree on confidence scores for key findings.
- Escalate if confidence scoring reveals that the overall research
  quality is below the promised standard.
