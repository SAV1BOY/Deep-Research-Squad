# Chief Conflict Resolution Gate

## Purpose

Ensure that all evidence conflicts, inter-agent disagreements, and
contradictory findings have been resolved or explicitly documented before
the research proceeds to synthesis and delivery.

## Gate Question

**Have all evidence conflicts been identified, analyzed, and resolved or
transparently disclosed?**

## Prerequisites

- Evidence Agent has flagged inconsistencies across sources.
- Verification Agent has completed cross-source checks.
- Contrarian Agent has submitted counter-arguments.
- All agents have had opportunity to respond to conflicting findings.
- Conflict log is populated with each disputed claim.

## Pass Criteria

1. Every flagged conflict has a resolution status: resolved, deferred,
   or disclosed-as-open.
2. Resolved conflicts include rationale citing source quality, recency,
   and methodological strength.
3. Deferred conflicts have a stated reason and an owner for follow-up.
4. Open conflicts are presented as balanced perspectives in the output.
5. No agent's findings were silently overridden without documented reason.
6. The stronger evidence position is identified for each conflict, even
   if both sides are presented.
7. Contrarian Agent confirms that counter-arguments were fairly evaluated.

## Fail Actions

- If conflicts are unlogged: halt synthesis and require Evidence Agent to
  produce a conflict inventory.
- If resolution rationale is missing: return to the resolving agent for
  written justification.
- If an agent's findings were silently dropped: restore them and document
  the reason for any exclusion.
- If Contrarian Agent disputes fair evaluation: convene a structured
  debate round before proceeding.

## Escalation Rules

- Escalate if the same conflict persists after two resolution attempts.
- Escalate if the conflict involves safety-critical or legally sensitive
  claims where an incorrect resolution carries material risk.
- Escalate if two agents produce irreconcilable conclusions from the same
  source material.
- Escalate if conflict resolution would require accessing restricted or
  classified sources beyond current authorization.
