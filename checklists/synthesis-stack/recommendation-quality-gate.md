# Recommendation Quality Gate

## Purpose

This gate ensures that all recommendations in the research output are
well-supported by evidence, actionable by the intended audience, and
appropriately scoped. Recommendations are the most consequential part of
research output because they directly influence decisions. Poorly formed
recommendations waste resources, create false confidence, or lead to
harmful actions.

## Gate Question

**Are recommendations supported and actionable?**

Each recommendation must be grounded in the synthesized evidence, feasible
for the intended audience to implement, and accompanied by sufficient
context for informed decision-making. Speculative recommendations must
be clearly labeled as such.

## Pass Criteria

1. Each recommendation links directly to specific synthesized findings and evidence.
2. Recommendations are stated in clear, actionable language with defined next steps.
3. The confidence level of each recommendation is explicitly stated.
4. Feasibility considerations (cost, time, resources, expertise) are addressed.
5. Risks and potential downsides of each recommendation are disclosed.
6. Alternative options are presented where the evidence supports multiple paths.
7. Recommendations are prioritized by impact, confidence, and feasibility.
8. Short-term and long-term recommendations are distinguished where applicable.
9. Dependencies between recommendations are identified and sequenced.
10. Each recommendation specifies its intended audience or decision-maker.
11. Speculative or forward-looking recommendations are clearly labeled as such.
12. Recommendations do not exceed the evidential warrant of the underlying research.
13. Implementation considerations and potential obstacles are noted.

## Fail Actions

- If a recommendation lacks evidence linkage, either find support or remove the recommendation.
- If recommendations are vague, rewrite with specific actions, owners, and timelines.
- If confidence levels are missing, assign them based on evidence strength assessment.
- If feasibility is unaddressed, add practical implementation considerations.
- If risks are omitted, conduct a brief risk assessment for each recommendation.
- If no alternatives are presented, investigate whether the evidence supports other paths.
- If prioritization is missing, rank recommendations using impact and confidence criteria.
- If speculative recommendations are unmarked, add explicit uncertainty labels.
- Do not release recommendations until they pass quality review.
