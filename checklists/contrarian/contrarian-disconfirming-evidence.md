# Contrarian Disconfirming Evidence Check

## Purpose

Verify that active searches for disconfirming evidence were conducted for
each major claim. Confirmation bias naturally leads researchers to seek
only supporting evidence; this gate counteracts that tendency.

## Gate Question

**Was disconfirming evidence actively sought for each major claim?**

## Prerequisites

- Major claims identified and listed.
- Supporting evidence already collected.
- Disconfirming search strategy planned.
- Search platforms and keywords for disconfirmation identified.

## Pass Criteria

1. At least one dedicated search for disconfirming evidence was conducted
   per major claim.
2. Disconfirming search used different keywords than the confirming search
   (e.g., "failure of X" instead of "success of X").
3. Sources known to hold contrarian positions were specifically consulted.
4. Any disconfirming evidence found is documented and evaluated.
5. The absence of disconfirming evidence is noted but not treated as
   proof of the claim.
6. Disconfirming evidence is weighed against confirming evidence using
   the same quality criteria.
7. Claims that survived disconfirmation attempts are flagged as more
   robust.

## Fail Actions

- If no disconfirming search was conducted: execute one before finalizing.
- If disconfirming keywords mirror confirming keywords: diversify them.
- If contrarian sources were not consulted: identify and review at least
  2 contrarian voices.
- If disconfirming evidence is undocumented: add it to the evidence log.
- If disconfirming evidence is dismissed without evaluation: apply the
  same quality rubric used for confirming evidence.

## Escalation Rules

- Escalate if disconfirming evidence is strong enough to undermine the
  primary conclusion.
- Escalate if the topic is one where contrarian views are actively
  suppressed and finding them requires special effort.
- Escalate if the agents show systematic bias in dismissing disconfirming
  evidence.
