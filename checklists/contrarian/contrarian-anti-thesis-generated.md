# Contrarian Anti-Thesis Generated Check

## Purpose

Ensure that a well-formulated anti-thesis has been generated for every major
thesis or conclusion. The anti-thesis forces rigorous testing of claims and
prevents confirmation bias.

## Gate Question

**Has a credible anti-thesis been generated for each major conclusion?**

## Prerequisites

- Major theses and conclusions identified.
- Evidence base reviewed.
- Domain knowledge sufficient to construct counter-arguments.
- Logical frameworks for argumentation available.

## Pass Criteria

1. Every major thesis has a corresponding anti-thesis stated clearly.
2. The anti-thesis is genuinely challenging (not a straw man).
3. The anti-thesis is internally consistent and logically coherent.
4. Evidence supporting the anti-thesis is cited (not fabricated).
5. The anti-thesis considers alternative interpretations of the same
   evidence.
6. The anti-thesis addresses the strongest form of the original thesis
   (steel-mans before attacking).
7. The outcome of the thesis-vs-anti-thesis evaluation is documented.

## Fail Actions

- If no anti-thesis exists for a major conclusion: generate one before
  proceeding.
- If the anti-thesis is a straw man: strengthen it to challenge the
  thesis genuinely.
- If no evidence supports the anti-thesis: search specifically for
  disconfirming evidence.
- If the evaluation is not documented: write up the comparison.
- If the anti-thesis is stronger than the thesis: reconsider the
  conclusion.

## Escalation Rules

- Escalate if the anti-thesis is compelling enough to overturn the
  primary conclusion.
- Escalate if generating a credible anti-thesis requires domain expertise
  the agents lack.
- Escalate if the thesis and anti-thesis are equally supported and no
  resolution is possible without additional evidence.
