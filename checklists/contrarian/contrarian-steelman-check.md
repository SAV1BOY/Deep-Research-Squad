# Contrarian Steelman Check

## Purpose

Ensure that opposing viewpoints are presented in their strongest possible
form before being evaluated. Steelmanning prevents the dismissal of valid
counter-arguments through weak representation.

## Gate Question

**Are opposing arguments presented in their strongest form?**

## Prerequisites

- Opposing viewpoints identified.
- Sources representing the opposing view collected.
- The best advocates for the opposing position identified.
- Core logic of the opposing argument understood.

## Pass Criteria

1. Each opposing argument is stated in the form its strongest proponents
   would recognize and accept.
2. The strongest evidence for the opposing view is cited, not the weakest.
3. The opposing argument's internal logic is presented as coherent (even
   if ultimately rejected).
4. Weaknesses in the primary thesis that the opposing view exploits are
   acknowledged.
5. The opposing view is attributed to credible sources, not fringe voices.
6. Refutation of the opposing view addresses its strongest form, not a
   weakened version.
7. If the opposing view cannot be refuted, this is honestly stated.

## Fail Actions

- If opposing arguments are in straw man form: rewrite them in steelman
  form using the best available sources.
- If only weak evidence is cited for the opposition: find and cite the
  strongest evidence.
- If refutation addresses a weakened version: redirect to the strongest
  form.
- If credible sources for the opposition are missing: search for domain
  experts who hold the opposing view.
- If an irrefutable opposing point exists: acknowledge it in the output.

## Escalation Rules

- Escalate if the steelmanned opposing argument is stronger than the
  primary thesis.
- Escalate if agents cannot construct a fair steelman due to domain
  knowledge limitations.
- Escalate if the opposing viewpoint represents a significant minority
  position that the requester may not want to see but should.
