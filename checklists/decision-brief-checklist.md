# Decision Brief Quality Checklist

## Purpose
Ensure that decision briefs present options, evidence, and trade-offs in a balanced and structured manner that enables informed decision-making. Unlike executive briefs that summarize research, decision briefs are specifically designed to frame a choice, compare alternatives, and facilitate a decision with clear criteria.

## When to Use
- Before delivering any decision brief to decision-makers
- When research must be translated into a structured decision framework
- During review of go/no-go, invest/divest, build/buy, or strategic choice analyses
- When a specific decision point has been identified and requires a recommendation

## Prerequisites
- The decision to be made is clearly identified and scoped
- Decision-maker and approval authority are identified
- Options or alternatives have been researched and evaluated
- Evaluation criteria have been agreed upon with stakeholders
- Relevant research, data, and analysis are complete
- Timeline and urgency for the decision are understood

## Checklist Items

### Section 1: Decision Framing
1. [ ] Decision question is stated clearly in the opening — PASS: unambiguous decision question; FAIL: vague or missing decision statement
2. [ ] Context and background for why this decision is needed now — PASS: urgency and context provided; FAIL: no triggering context
3. [ ] Decision-maker and approval process are identified — PASS: governance clear; FAIL: decision authority unclear
4. [ ] Decision timeline and deadline are stated — PASS: timeline explicit; FAIL: no temporal frame
5. [ ] Consequences of not deciding (status quo option) are described — PASS: inaction scenario included; FAIL: status quo not analyzed

### Section 2: Options and Alternatives
6. [ ] At least 3 viable options are presented — PASS: 3+ options; FAIL: binary choice without justification
7. [ ] Each option is described with sufficient detail to evaluate — PASS: substantive descriptions; FAIL: superficial option summaries
8. [ ] Options span a meaningful range of approaches — PASS: diverse options; FAIL: options are minor variations of each other
9. [ ] Each option includes cost estimate or resource requirements — PASS: cost data per option; FAIL: costs not estimated
10. [ ] Implementation timeline is estimated for each option — PASS: timelines per option; FAIL: no implementation planning

### Section 3: Evaluation Framework
11. [ ] Evaluation criteria are explicitly listed — PASS: criteria defined; FAIL: implicit or missing criteria
12. [ ] Criteria are weighted by importance to the decision — PASS: weights assigned; FAIL: unweighted criteria
13. [ ] Each option is scored against each criterion — PASS: systematic scoring; FAIL: narrative evaluation without structured comparison
14. [ ] Scoring methodology is transparent and defensible — PASS: methodology explained; FAIL: opaque scoring
15. [ ] Sensitivity analysis shows how different weights change the recommendation — PASS: sensitivity tested; FAIL: single weighting only

### Section 4: Risk and Trade-Off Analysis
16. [ ] Key risks for each option are identified — PASS: risk inventory per option; FAIL: risks not analyzed
17. [ ] Trade-offs between options are explicitly stated — PASS: trade-offs articulated; FAIL: trade-offs implied but not stated
18. [ ] Reversibility of each option is assessed — PASS: reversibility noted; FAIL: lock-in effects not considered
19. [ ] Dependencies and prerequisites for each option are mapped — PASS: dependencies listed; FAIL: dependency blind spots
20. [ ] Downside scenarios for the recommended option are presented — PASS: honest downside assessment; FAIL: recommendation without risk acknowledgment

### Section 5: Recommendation and Evidence
21. [ ] A clear recommendation is made with supporting rationale — PASS: explicit recommendation with reasoning; FAIL: options presented without recommendation
22. [ ] Recommendation links to evaluation scores and evidence — PASS: evidence-based recommendation; FAIL: opinion-based recommendation
23. [ ] Dissenting views or arguments against the recommendation are noted — PASS: counter-arguments presented; FAIL: one-sided advocacy
24. [ ] Confidence level in the recommendation is stated — PASS: confidence rated; FAIL: no confidence assessment
25. [ ] Immediate next steps following the decision are outlined — PASS: action plan ready; FAIL: decision without implementation path

### Section 6: Format and Presentation
26. [ ] Brief is concise (under 5 pages excluding appendices) — PASS: within length; FAIL: overly long
27. [ ] Comparison table or matrix enables at-a-glance evaluation — PASS: visual comparison present; FAIL: text-only comparison
28. [ ] Supporting data and detailed analysis are in appendices — PASS: main brief is clean with detail in appendices; FAIL: excessive detail in main body

## Scoring
- Count the total number of items marked PASS
- Quality Score = (PASS count / 28) x 100
- Grade thresholds:
  - 95-100%: Excellent — decision-ready brief
  - 85-94%: Good — minor refinements needed
  - 75-84%: Acceptable — gaps to address before the decision meeting
  - Below 75%: Insufficient — brief not ready to support a decision

## Escalation
- **Accept**: Score of 85% or above with no FAIL on items 1, 6, 11, 21, or 23
- **Revise**: Score of 75-84%, or any FAIL on items 1, 6, 11, 21, or 23
- **Escalate to lead**: Score below 75%, or evaluation framework is contested, or available options do not adequately address the decision
- **Escalate to stakeholder**: Decision question itself needs reframing, or new information materially changes the option landscape, or timeline prevents adequate analysis of all viable options
