# Source Trust Gate

## Purpose

This gate ensures that every source used in the research has been evaluated
for trustworthiness before its claims are incorporated into findings. Relying
on unvetted sources introduces misinformation risk, weakens conclusions, and
undermines the credibility of the entire research output. This gate enforces
systematic source evaluation as a prerequisite to evidence acceptance.

## Gate Question

**Can we trust these sources?**

Each source must be evaluated on authority, accuracy, objectivity, currency,
and provenance. Sources that fail evaluation must be flagged, downweighted,
or excluded with documented rationale.

## Pass Criteria

1. Every source has been assessed for author or institutional authority and expertise.
2. The publication or platform reputation has been evaluated for each source.
3. Potential conflicts of interest or funding biases have been identified and documented.
4. Source currency has been verified relative to the research time boundaries.
5. Primary data sources have been checked for methodology transparency.
6. Claims from anonymous or pseudonymous sources are flagged and corroborated independently.
7. Sources with known editorial or ideological leanings are balanced with opposing viewpoints.
8. Statistical claims have been checked for sample size, methodology, and reproducibility.
9. Each source has been assigned a trust tier (high, medium, low) with documented rationale.
10. No single source bears disproportionate weight in the evidence base without justification.
11. Source provenance chains are traceable for secondary and tertiary sources.
12. Sources that fail trust evaluation are explicitly excluded or flagged with caveats.

## Fail Actions

- If author authority cannot be verified, search for corroborating sources or downweight.
- If conflicts of interest are discovered, document them and seek independent confirmation.
- If sources are outdated relative to scope boundaries, find current alternatives.
- If a source lacks methodology transparency, flag the limitation on any derived claims.
- If the evidence base is dominated by a single source, actively seek alternatives.
- If trust tiers have not been assigned, complete the assessment before using any source.
- If source bias is detected, add counterbalancing sources or note the gap explicitly.
- Maintain a source trust registry in the research log for all evaluated sources.
- Do not incorporate claims from unevaluated sources into findings.
