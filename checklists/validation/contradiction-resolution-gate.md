# Contradiction Resolution Gate

## Purpose

This gate ensures that contradictions in the evidence base are identified,
analyzed, and either resolved or transparently documented before synthesis.
Unaddressed contradictions undermine the reliability of conclusions and
erode trust in the research output. This gate prevents contradictions from
being silently ignored or superficially dismissed.

## Gate Question

**Are contradictions resolved or documented?**

Every identified contradiction between sources, data points, or expert
opinions must be systematically analyzed. Contradictions must be resolved
through deeper investigation or explicitly documented with impact analysis
when resolution is not possible.

## Pass Criteria

1. A systematic scan for contradictions across the evidence base has been performed.
2. Each identified contradiction is logged with the specific sources and claims involved.
3. The nature of each contradiction is classified (factual, methodological, interpretive, temporal).
4. Root cause analysis has been attempted for each contradiction.
5. Resolvable contradictions have been resolved with documented reasoning.
6. Unresolvable contradictions are explicitly disclosed in the research output.
7. The impact of each unresolved contradiction on conclusions is assessed and stated.
8. Where contradictions arise from methodological differences, the stronger methodology is identified.
9. Temporal contradictions are resolved by identifying which data is more current and relevant.
10. Stakeholder or perspective-based contradictions are presented as legitimate alternative views.
11. No contradiction has been silently dropped or ignored without documentation.
12. The research output acknowledges the degree of consensus versus disagreement on key points.

## Fail Actions

- If no contradiction scan has been performed, conduct one before proceeding to synthesis.
- If contradictions are found but unlogged, create a contradiction register immediately.
- If root cause analysis is missing, investigate whether differences stem from data, method, or interpretation.
- If resolvable contradictions remain unresolved, prioritize resolution of those affecting key conclusions.
- If unresolved contradictions lack impact assessments, analyze how they affect each conclusion.
- If contradictions are silently ignored in the output, add explicit disclosure sections.
- If methodological superiority cannot be determined, present both positions with caveats.
- Escalate persistent contradictions that affect core conclusions to a senior reviewer.
- Do not proceed to synthesis until all contradictions are resolved or documented.
