# Literature Taxonomy Quality Check

## Purpose

Assess whether the literature has been organized into a coherent taxonomy
or classification system that enables meaningful comparison and synthesis.
A poor taxonomy leads to disorganized findings.

## Gate Question

**Is the literature organized in a high-quality, coherent taxonomy?**

## Prerequisites

- Literature corpus collected and catalogued.
- Initial categorization attempted.
- Domain frameworks available for reference.
- Sufficient volume of sources to warrant organization (typically 10+).

## Pass Criteria

1. Papers and sources are grouped by theme, methodology, or perspective
   in a logical structure.
2. The taxonomy is MECE (categories do not overlap and collectively cover
   the corpus).
3. Category labels are clear and would be recognizable to a domain expert.
4. The taxonomy reveals patterns: which areas are well-studied vs. sparse.
5. Cross-cutting dimensions (e.g., theoretical vs. empirical, qualitative
   vs. quantitative) are represented.
6. The taxonomy has at most 3 levels of depth to remain usable.
7. Each source is assigned to exactly one primary category (with
   cross-references where relevant).

## Fail Actions

- If categories overlap: redraw boundaries or merge.
- If categories miss significant sources: add new categories.
- If labels are unclear: rename using standard domain terminology.
- If taxonomy is too flat (one level): add a second level for the
   largest categories.
- If taxonomy is too deep (4+ levels): simplify by merging sub-categories.

## Escalation Rules

- Escalate if the literature spans multiple disciplines with incompatible
  classification systems.
- Escalate if the taxonomy reveals that the research question actually
  spans distinct fields requiring separate treatment.
- Escalate if no domain framework exists to guide the taxonomy and
  expert input is needed.
