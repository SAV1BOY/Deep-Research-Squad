# Audit Completeness Check

## Purpose

Verify that the research output addresses every element of the original
scope and that no promised deliverable is missing. This is the final
completeness check before delivery.

## Gate Question

**Does the output address every element of the approved scope?**

## Prerequisites

- Approved scope document with sub-questions and boundaries.
- Final synthesis document.
- Deliverable checklist from the scope agreement.
- All agent outputs reviewed.

## Pass Criteria

1. Every sub-question from the scope is addressed in the output.
2. All promised deliverable formats are present (report, data tables,
   visualizations, etc.).
3. The executive summary covers the key findings and recommendations.
4. The limitations section is present and substantive.
5. All citations are included and formatted correctly.
6. Appendices contain supporting detail as promised.
7. The output meets the minimum quality bar for each section (no
   placeholder text, no incomplete analyses).

## Fail Actions

- If a sub-question is unaddressed: add the missing analysis or document
  why it could not be answered.
- If a deliverable format is missing: create it or explain the omission.
- If the executive summary is absent or thin: write or expand it.
- If limitations section is missing: add it.
- If citations are incomplete: fill in the missing references.
- If placeholder text remains: complete or remove it.

## Escalation Rules

- Escalate if critical sub-questions cannot be answered and the output
  is significantly incomplete.
- Escalate if the output fails to meet the quality bar after one
  remediation attempt.
- Escalate if completeness issues are discovered that require
  re-opening research phases.
