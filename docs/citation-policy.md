# Citation Policy

## Purpose

This policy governs how the Deep Research Squad cites sources in all
deliverables. Proper citation enables traceability, credibility assessment,
and intellectual honesty. Every claim must trace to its origin.

## Core Rules

### Rule 1: Cite Every Factual Claim

No factual claim may appear without attribution. This includes statistics,
dates, descriptions of events, and characterizations of positions.

### Rule 2: Use Consistent Format

All citations follow the format defined in `voice/language-guides/citation-style.md`.
Inline: (Author, Year). Reference list: Author. (Year). Title. Source. URL [Accessed: Date].

### Rule 3: Record Access Dates

Web sources must include the date they were accessed. Content may change
or disappear. The access date establishes what the source said when we used it.

### Rule 4: Classify Every Source

Every cited source must be classified with:
- Source type code (PR, GV, IR, NM, CF, EI, BO, SM, AN).
- Evidence tier (1 through 5).
- Conflict of interest flag if applicable.

### Rule 5: Distinguish Primary from Secondary

When citing a secondary source that reports on primary data, cite both:
"According to [Primary] (as reported by [Secondary], Year)..."

### Rule 6: Flag Interested Parties

Sources produced by entities with a financial or advocacy interest in the
topic must be flagged: "(Smith, 2025 [vendor report])".

### Rule 7: Archive Volatile Sources

Sources that may disappear (web pages, social media posts, temporary
publications) must be archived at the time of access.

## Citation Density by Format

| Format           | Citation Requirement                          |
|------------------|-----------------------------------------------|
| Deep dive        | Every factual claim cited inline              |
| Executive brief  | Key findings cited; full refs linked           |
| Synthesis        | Per-finding attribution; source index          |
| Slack update     | Source count: "Based on N sources, Tier X-Y"   |
| Presentation     | Source on each data slide; full refs in appendix|

## Special Cases

### AI-Generated Content

If AI tools contributed to the research, disclose the tool, model version,
and date. AI outputs are not independently verified unless stated.

### Interviews

Record: name/role, organization, date, on/off record status.
Classify as Tier 3 (Expert Interview) unless corroborated.

### Anonymous Sources

Classify as Tier 5 (Unverified). Do not base conclusions solely on anonymous
sources. Seek corroboration from named sources.

## Citation Audit

The Evidence Auditor checks at Gate 5 that every claim has a citation,
citations are formatted consistently, source classifications are accurate,
and access dates are present for web sources.

## Quality Check

- Is every factual claim cited?
- Are all sources classified by type and tier?
- Are access dates recorded?
- Are interested parties flagged?
- Is the reference list complete and consistently formatted?
