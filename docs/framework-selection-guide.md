# Framework Selection Guide

## Purpose

This guide helps agents select the appropriate analytical framework for
a given research question. The right framework structures thinking and
prevents ad hoc analysis. The wrong framework forces the question into
an ill-fitting structure.

## Framework Selection Criteria

Before selecting a framework, assess:

1. **Question type:** Is it descriptive, predictive, evaluative, or prescriptive?
2. **Data availability:** What type and quality of data is accessible?
3. **Audience:** What level of sophistication does the reader expect?
4. **Time constraint:** Does the framework fit the available timeline?
5. **Prior use:** Has this framework been used on similar questions before?

## Framework Catalog

### Market and Competitive Analysis

| Framework          | Best For                                    |
|--------------------|---------------------------------------------|
| Porter's Five Forces | Industry structure and competitive dynamics|
| SWOT               | Quick situational assessment                |
| Value Chain        | Understanding competitive advantage sources |
| TAM/SAM/SOM       | Market sizing and opportunity assessment    |

### Strategic Analysis

| Framework          | Best For                                    |
|--------------------|---------------------------------------------|
| Scenario Planning  | High-uncertainty, long-horizon questions     |
| Decision Matrix    | Comparing options with multiple criteria     |
| PESTEL             | Macro-environment scanning                   |
| Ansoff Matrix      | Growth strategy evaluation                   |

### Evidence and Argumentation

| Framework          | Best For                                    |
|--------------------|---------------------------------------------|
| Toulmin Model      | Structuring evidence-based arguments         |
| ACH                | Testing multiple competing hypotheses        |
| Bayesian Updating  | Revising probabilities with new evidence     |
| Pre-mortem         | Anticipating failure modes                   |

### Causal and Systems Analysis

| Framework          | Best For                                    |
|--------------------|---------------------------------------------|
| Root Cause Analysis| Understanding why something happened         |
| Systems Mapping    | Identifying feedback loops and dependencies  |
| Fishbone Diagram   | Categorizing potential causes                |

## Selection Decision Tree

1. **Is the question about what happened?** Use diagnostic frameworks.
2. **Is the question about what might happen?** Use predictive frameworks.
3. **Is the question about which option is best?** Use evaluative frameworks.
4. **Is the question about what to do?** Use prescriptive frameworks.

## Combining Frameworks

Some questions require multiple frameworks:
- Market entry: TAM/SAM/SOM + Porter's Five Forces + Scenario Planning.
- Competitive threat: SWOT + ACH + Pre-mortem.
- Strategy review: PESTEL + Scenario Planning + Decision Matrix.

When combining, specify which framework addresses which sub-question.

## Framework Disclosure

Always disclose the framework used in the methodology section.
Explain why it was selected over alternatives and note its limitations.

## Common Mistakes

- Selecting a framework because it is familiar, not because it fits.
- Forcing the question into the framework.
- Using a single framework when the question requires multiple lenses.
- Not disclosing the framework to the reader.

## Quality Check

- Is the framework appropriate for the question type?
- Was the selection justified over alternatives?
- Is the framework disclosed in the deliverable?
- Are framework limitations acknowledged?
