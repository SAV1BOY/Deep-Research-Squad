# Changelog

## Purpose

This document records significant changes to the Deep Research Squad's
documentation, policies, and processes. It provides a chronological record
of what changed, when, and why.

## Format

Each entry follows this structure:
```
### [Date] - [Category]
- **Change:** What was added, modified, or removed.
- **Rationale:** Why the change was made.
- **Affected documents:** Which files were updated.
```

## Categories

| Category       | Description                                   |
|----------------|-----------------------------------------------|
| Policy         | Changes to evidence, citation, or uncertainty policies |
| Process        | Changes to workflows, gates, or escalation     |
| Voice          | Changes to tone profiles, language guides      |
| Phrases        | New or updated language patterns               |
| Docs           | New or updated documentation                   |
| Structure      | Changes to directory structure or naming        |

## How to Add Entries

1. Add new entries at the top of the Entries section (reverse chronological).
2. Follow the entry format above.
3. Use the appropriate category tag.
4. Be specific about what changed and why.
5. List all affected documents.

## Retention

All changelog entries are permanent. Do not delete or modify past entries.
If a past entry contains an error, add a correction entry referencing it.

## Review Cadence

The changelog is reviewed monthly to identify patterns in changes,
verify that all changes have been logged, and assess whether the pace
of change is sustainable.

## Quality Check

- Is every significant change logged?
- Are entries in reverse chronological order?
- Is the rationale for each change clear?
- Are affected documents listed?
