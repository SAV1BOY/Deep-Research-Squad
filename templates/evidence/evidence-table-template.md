## Column Definitions

### Evidence Type
- **Primary:** Original data, direct observation, official documents, interviews
- **Secondary:** Analysis of primary data, review articles, reports citing originals
- **Statistical:** Quantitative data from datasets, surveys, measurements
- **Anecdotal:** Individual accounts, case studies, informal observations

### Strength Assessment
- **Strong:** Multiple independent sources confirm; methodology is sound; data is recent
- **Moderate:** Some corroboration exists; methodology is acceptable; minor caveats
- **Weak:** Single source; unverified; methodology concerns; outdated data

### Confidence Level
- **High:** Claim is well-supported, low uncertainty, would be surprising if wrong
- **Medium:** Claim is supported but with caveats, moderate uncertainty
- **Low:** Claim is plausible but poorly supported, high uncertainty

> Instruction: Apply these definitions consistently across all evidence entries.
