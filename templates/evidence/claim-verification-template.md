## Verification Methods Guide

| Method | Description | When to Use |
|--------|-------------|-------------|
| **Cross-reference** | Check claim against 2+ independent sources | Default method for most factual claims |
| **Primary source check** | Trace claim back to its original source | When a claim is cited second-hand or paraphrased |
| **Data verification** | Reproduce calculation or check raw data | For statistical claims, percentages, financial figures |
| **Expert validation** | Consult domain expert for assessment | For technical or specialized claims |
| **Official records** | Check against government or regulatory filings | For legal, corporate, or regulatory claims |
| **Temporal check** | Verify the claim was accurate at stated date | For claims that may have been true but are now outdated |

> Instruction: Select the most appropriate method for each claim type.
> Document which method was used so the verification is reproducible.
