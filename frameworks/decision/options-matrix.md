# Options Matrix

## Purpose
A structured evaluation tool for comparing multiple options against weighted criteria. Transforms subjective option comparison into a transparent, repeatable process where criteria, weights, and scores are explicit. Prevents decisions driven by gut feeling or anchoring on a single dimension.

## When to Use
- When choosing between three or more distinct options
- When multiple evaluation criteria matter and trade-offs are unavoidable
- When multiple stakeholders need to agree on a decision and transparency is essential
- When you need to document the rationale behind a choice for accountability

## Inputs
- A set of viable options (typically three to seven)
- Evaluation criteria relevant to the decision
- Stakeholder input on criteria importance
- Evidence and analysis for scoring each option against each criterion
- Confidence levels for each score

## Process

### 1. Define Options
List all viable options to be evaluated:
- Include the status quo or "do nothing" option as a baseline
- Ensure options are genuinely distinct, not minor variations
- Remove obviously dominated options (worse on all criteria than another option)
- Describe each option in sufficient detail for consistent evaluation

### 2. Select Criteria
Choose three to seven evaluation criteria:
- Criteria should be relevant to the decision and differentiating between options
- Include both quantitative criteria (cost, time, measurable impact) and qualitative criteria (strategic fit, risk, flexibility)
- Ensure criteria are independent; avoid double-counting the same factor under different names
- Common criteria include: effectiveness, feasibility, cost, speed, risk, scalability, reversibility, stakeholder acceptance

### 3. Assign Weights
Distribute 100 points across criteria to reflect their relative importance:
- Gather stakeholder input on weights before scoring options to prevent manipulation
- Document the rationale for each weight
- Test sensitivity: if reasonable alternative weights would change the outcome, note this
- Ensure no single criterion dominates unless genuinely warranted

### 4. Score Options
Rate each option against each criterion on a consistent scale (1 to 5 or 1 to 10):
- 1 = performs very poorly on this criterion
- 5 (or 10) = performs excellently on this criterion
- Base scores on evidence wherever possible, not assumption
- Note the confidence level for each score (high, medium, low)
- Where scores are contested, document the range and reasoning

### 5. Calculate Weighted Scores
For each option, compute the total weighted score:
- Weighted score per criterion = score multiplied by weight
- Total score = sum of weighted scores across all criteria
- Rank options by total score
- Present results in a matrix table for visual comparison

### 6. Sensitivity Analysis
Test how robust the ranking is:
- Vary weights by plus or minus 10 to 20 percent on key criteria
- Vary contested scores by plus or minus one point
- Identify if the top option changes under reasonable alternative assumptions
- If the ranking is fragile, report this explicitly

### 7. Interpret Results
The matrix informs but does not dictate the decision:
- A clear winner with robust scores across sensitivity analysis is a strong signal
- A close race between top options means the decision depends on judgment calls about weights
- An option that scores highest but has a very low score on one critical criterion may carry unacceptable risk

## Outputs
- A completed options matrix with criteria, weights, scores, and weighted totals
- A ranking of options with the scoring rationale
- Sensitivity analysis results showing ranking robustness
- A narrative interpreting the results and noting key trade-offs

## Common Pitfalls
- **Criteria gaming**: Choosing criteria or weights to justify a preferred option. Set criteria and weights before scoring.
- **False precision**: A score of 7.3 versus 7.1 is meaningless. Do not over-interpret small differences in total scores.
- **Too many criteria**: More than seven criteria create noise and dilute the differentiating factors. Consolidate overlapping criteria.
- **Equal weights by default**: Giving all criteria equal weight is a decision in itself. Be intentional about weights.
- **Ignoring qualitative factors**: The matrix captures scored dimensions but may miss intangibles. Note important factors that the matrix does not capture.
- **Matrix as final answer**: The matrix is a decision support tool, not a decision-making machine. Human judgment interprets the results.
