# Scenario Analysis Framework

## Purpose
A structured approach to exploring multiple plausible futures when the outcome is uncertain. Rather than predicting a single future, scenario analysis builds several coherent narratives about how events might unfold, enabling strategies that are robust across different possibilities.

## When to Use
- When the decision environment has high uncertainty on multiple dimensions
- When the time horizon extends beyond reliable forecasting (typically more than one year)
- When the stakes are high enough to justify preparing for multiple outcomes
- When key assumptions could reasonably go either way

## Inputs
- Key research findings and their confidence levels
- Identified uncertainties and variables that could evolve differently
- Stakeholder concerns and strategic priorities
- Historical precedents and analogies where available

## Process

### 1. Identify Key Drivers
Determine the forces that will most shape the future:
- List all variables that could significantly affect outcomes
- Rate each by impact (how much it matters) and uncertainty (how unpredictable it is)
- Select two to three drivers that are both high-impact and high-uncertainty
- These become the axes around which scenarios are built

### 2. Build Scenario Matrix
Construct scenarios from the key drivers:
- For two key drivers, create a 2x2 matrix with four scenarios
- For three drivers, select the most informative combinations (typically four to six scenarios)
- Name each scenario with a memorable, descriptive title
- Ensure scenarios are plausible (could actually happen), distinct (meaningfully different), and challenging (not all comfortable)

### 3. Develop Scenario Narratives
For each scenario, write a coherent story:
- Describe the path from present to future: what events and trends lead to this scenario?
- Identify the timeline: when do key shifts occur?
- Describe the end state: what does the world look like in this scenario?
- Include specific, concrete details that make the scenario vivid and testable
- Keep each narrative to one page

### 4. Assess Implications per Scenario
For each scenario, analyze the consequences:
- What opportunities emerge in this scenario?
- What threats materialize?
- How are different stakeholders affected?
- What capabilities or resources become most valuable?
- What current strategies succeed or fail?

### 5. Develop Robust Strategies
Identify approaches that perform well across scenarios:
- **No-regret moves**: Actions that are beneficial regardless of which scenario unfolds
- **Options**: Investments that create flexibility to pivot as the future clarifies
- **Hedges**: Actions that protect against downside scenarios
- **Big bets**: High-return moves contingent on specific scenarios, taken only when justified
- For each strategy, note which scenarios it is optimized for and where it is vulnerable

### 6. Define Early Warning Indicators
For each scenario, identify signals that would indicate it is becoming reality:
- What observable events or data points would confirm this trajectory?
- How early could these signals be detected?
- What monitoring system should be established?
- What decision triggers should be set (if signal X occurs, execute plan Y)?

## Outputs
- A set of four to six named, developed scenarios with narratives
- Implication assessment for each scenario across stakeholders
- A strategy menu categorized by robustness (no-regret, options, hedges, big bets)
- Early warning indicators with monitoring recommendations

## Common Pitfalls
- **Best case / worst case thinking**: Scenarios should not be optimistic versus pessimistic. They should vary on the key uncertain drivers.
- **Too many scenarios**: More than six scenarios overwhelms analysis. Four is the practical optimum for most situations.
- **Implausible scenarios**: Each scenario must be possible, not just imaginable. Ground scenarios in real forces and trends.
- **Identical strategies across scenarios**: If your strategy does not change across scenarios, either the scenarios are too similar or the analysis is too superficial.
- **Treating scenarios as predictions**: Scenarios are tools for thinking, not forecasts. No scenario will unfold exactly as described.
- **Neglecting the monitoring plan**: Without early warning indicators, scenario analysis is an academic exercise. The value is in knowing when to pivot.
