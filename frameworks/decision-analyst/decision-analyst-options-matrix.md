# Options Matrix Framework

## Purpose

Create a comprehensive options matrix that lays out every viable option for a decision, with each option described in a consistent structure: description, pros, cons, risks, resources needed, reversibility, and expected outcome. This ensures apples-to-apples comparison and prevents options from being dismissed or favored without rigorous evaluation.

## When to Use

- When a decision involves three or more distinct options.
- When stakeholders are anchored on one option and need to see alternatives fairly presented.
- When the decision is significant enough to warrant systematic evaluation before committing.
- When building the foundation for a recommendation that must be defensible.

## Inputs

- The decision context: what is being decided and why.
- A list of candidate options, including the status quo.
- Information about constraints (budget, time, political, technical).
- Stakeholder priorities and success criteria.

## Process

### Step 1: Option Generation
Generate a comprehensive list of options. Techniques:
- **Brainstorm broadly**: Include conventional and unconventional options.
- **Include the status quo**: Doing nothing is always an option and serves as the baseline.
- **Include hybrid options**: Combinations of elements from different pure options.
- **Challenge constraints**: Ask "what would we do if [constraint] did not exist?" to generate creative options.
Aim for 3-7 options. Fewer than 3 suggests insufficient exploration. More than 7 becomes unwieldy.

### Step 2: Option Description
For each option, write a clear, neutral description (2-4 sentences) covering:
- What the option entails (the action to be taken).
- How it differs from the status quo.
- What its theory of change is (why it would produce the desired outcome).

### Step 3: Pros Analysis
For each option, list concrete advantages:
- What does this option achieve that alternatives do not?
- What unique strengths does it offer?
- Who benefits and how?
- Support each pro with evidence where possible.

### Step 4: Cons Analysis
For each option, list concrete disadvantages:
- What does this option sacrifice or make harder?
- What weaknesses does it have?
- Who is disadvantaged and how?
- Be equally rigorous with cons as with pros. Resist the temptation to soften cons for preferred options.

### Step 5: Risk Assessment
For each option, identify the key risks:
- What could go wrong?
- What is the probability of each risk materializing?
- What is the impact if it does?
- What can be done to mitigate each risk?
- Are there risks unique to this option that others do not share?

### Step 6: Resource Requirements
For each option, estimate the resources needed:
- Financial cost (upfront and ongoing).
- Time to implement.
- People and skills required.
- Organizational or political capital needed.
- Opportunity cost (what else could these resources be used for).

### Step 7: Reversibility Assessment
For each option, evaluate how reversible it is:
- **Fully reversible**: Can be undone completely at low cost.
- **Partially reversible**: Can be undone but with some cost or loss.
- **Irreversible**: Cannot be undone once committed. Sunk costs are real.
Irreversible options demand higher certainty before committing.

### Step 8: Expected Outcome
For each option, state the expected outcome if the option is executed as planned:
- What does success look like?
- What is the most likely outcome (not the best case)?
- What is the timeline for results to become visible?
- How will success be measured?

### Step 9: Matrix Assembly
Compile all information into a structured matrix format for side-by-side comparison.

## Outputs

- A completed options matrix with consistent entries for each option across all seven dimensions.
- A side-by-side comparison view highlighting key differentiators.
- Identification of the option(s) that dominate (better on every dimension) and those that are dominated (worse on every dimension).
- A narrative summary of the most important trade-offs between options.

## Common Pitfalls

- **Missing the status quo**: Forgetting to include "do nothing" as a baseline for comparison.
- **Straw man options**: Including obviously bad options to make the preferred one look better.
- **Asymmetric analysis**: Analyzing the preferred option in more depth and detail than alternatives.
- **Ignoring resource constraints**: Describing options without accounting for what they cost.
- **Binary thinking**: Presenting only two options when more exist. The best option is often the third one nobody initially considered.
- **Sunk cost inclusion**: Letting resources already spent influence the evaluation of forward-looking options.
