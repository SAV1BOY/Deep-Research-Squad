# Contradiction Mapping Framework

## Purpose
Systematically identify, classify, and resolve contradictions between sources
during research. Contradictions are not errors to ignore but signals that
require structured analysis to determine which position is better supported
or whether the truth lies in synthesis.

## When to Use
- Two or more sources disagree on facts, interpretations, or conclusions.
- A new finding conflicts with previously accepted information.
- Expert opinions diverge on the same topic.
- Research results from different methodologies point in different directions.
- A claim seems internally inconsistent.

## Inputs
- Two or more conflicting claims or data points.
- Sources and context for each conflicting position.
- Evidence supporting each side.
- Metadata: dates, methodologies, authors, domains.

## Process

### Step 1: Identify the Contradiction
- State each conflicting position precisely and neutrally.
- Confirm it is a genuine contradiction, not a misreading or scope difference.
- Check if the claims address the exact same question or subtly different ones.
- Determine if the contradiction is binary (A vs not-A) or scalar (A vs B on a spectrum).

### Step 2: Classify the Contradiction Type

**Factual Contradiction**
- Definition: Sources disagree on verifiable facts (numbers, dates, events).
- Example: "Company revenue was $5M" vs "Company revenue was $8M."
- Resolution priority: Primary data > secondary reports. Official records > estimates.

**Interpretive Contradiction**
- Definition: Sources agree on facts but disagree on what they mean.
- Example: Both cite same data but one concludes growth, another stagnation.
- Resolution priority: Evaluate reasoning quality and unstated assumptions.

**Methodological Contradiction**
- Definition: Different research methods produce different results.
- Example: Survey says X, controlled experiment says Y.
- Resolution priority: Higher Evidence Ladder rung generally prevails.

**Temporal Contradiction**
- Definition: Information was true at one time but not another.
- Example: Policy was X in 2020 but changed to Y in 2023.
- Resolution priority: Most recent authoritative source, unless historical context matters.

### Step 3: Gather Resolution Evidence
- For each side, collect and classify supporting evidence using the Evidence Ladder.
- Identify the strongest evidence for each position.
- Check for sources that acknowledge both positions.
- Look for meta-analyses or systematic reviews that address the disagreement.

### Step 4: Apply Resolution Strategies

**Strategy 1: Triangulation**
- Seek a third (or more) independent source.
- If majority of independent sources agree, weight toward that position.
- Apply Source Triangulation framework for rigorous evaluation.

**Strategy 2: Recency Analysis**
- Determine if newer evidence supersedes older findings.
- Check if the field has evolved in ways that explain the contradiction.
- Note: Newer is not automatically better. Evaluate methodology equally.

**Strategy 3: Authority Assessment**
- Compare the domain authority of conflicting sources.
- Institutional expertise, track record, and peer recognition matter.
- Beware: authority is one signal among many, not a trump card.

**Strategy 4: Methodology Comparison**
- Evaluate the rigor of each source's methodology.
- Larger sample sizes, better controls, and peer review strengthen a position.
- Identify methodological flaws that could explain the discrepancy.

**Strategy 5: Synthesis**
- Determine if both positions can be partially true under different conditions.
- Look for moderating variables that explain when each position holds.
- Construct a unified model that accommodates both findings.

### Step 5: Document the Resolution
- State the resolution clearly: which position is favored, why, and with what confidence.
- If unresolved, document it as an open question with evidence for both sides.
- Note what additional evidence would definitively resolve the contradiction.

## Outputs
- Contradiction register listing all identified contradictions.
- Classification of each contradiction by type.
- Resolution for each (or explicit documentation of unresolved contradictions).
- Confidence score for the favored position.
- Impact assessment: how does the contradiction affect overall findings?

## Common Pitfalls
- **Premature resolution**: Choosing a side without sufficient analysis because
  it matches prior expectations.
- **False equivalence**: Treating both sides as equally valid when evidence
  clearly favors one. Balance is not always accuracy.
- **Missing the real disagreement**: Surface contradictions may mask deeper
  agreement or vice versa. Clarify what exactly is in dispute.
- **Resolution bias**: Preferring synthesis when one side is simply wrong,
  or preferring one side when synthesis is appropriate.
- **Ignoring unresolvable contradictions**: Some contradictions cannot be resolved
  with available evidence. Report them honestly.

## Related Frameworks
- **Evidence Ladder**: Provides the scale for comparing evidence strength.
- **Confidence Weighting**: Assigns scores to each competing position.
- **Source Triangulation**: Core technique for the triangulation resolution strategy.
- **First-Principles Research**: Useful when contradictions stem from flawed assumptions.

### Contradiction Register
```
CONTRADICTION #[N]
Type: [Factual | Interpretive | Methodological | Temporal]

Position A: [Statement]
  Source: [Source details]
  Evidence Rung: [1-9]
  Key support: [Summary]

Position B: [Statement]
  Source: [Source details]
  Evidence Rung: [1-9]
  Key support: [Summary]

RESOLUTION STRATEGY APPLIED: [Triangulation | Recency | Authority | Methodology | Synthesis]
RESOLUTION: [Which position is favored, or synthesis statement]
CONFIDENCE: [0.0-1.0]
REMAINING UNCERTAINTY: [What would change this resolution]
IMPACT ON FINDINGS: [How this affects the overall research]
```
