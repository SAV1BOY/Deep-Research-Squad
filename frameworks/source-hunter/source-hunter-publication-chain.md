# Publication Chain Framework

## Purpose
Trace the citation and publication chain from the source in hand back to the original source of a claim or data point. Detects broken chains, misattributions, and the dangerous pattern of circular citations where sources appear to corroborate each other but all trace back to a single origin.

## When to Use
- When a claim appears in multiple sources and you need to verify it is not a single-origin claim amplified through repetition.
- When a citation seems suspicious or too convenient.
- When building high-confidence evidence for critical claims.
- When secondary sources disagree about what a primary source says.

## Inputs
- A source making a specific claim.
- The citations or references provided by that source.
- Access to the cited sources for verification.

## Process

### Step 1: Identify the Claim and Its Immediate Source
- State the specific claim in precise terms.
- Record the source that presents this claim.
- Note whether the source attributes the claim to another source or presents it as original.

### Step 2: Follow the Citation One Link Back
- If the source cites another source for this claim, locate that cited source.
- Read the cited source. Does it actually make this claim?
- If yes, does the cited source present original evidence or cite yet another source?
- Record each link in the chain.

### Step 3: Continue Until You Reach the Origin
- Repeat Step 2 until you reach a source that presents original evidence (primary source).
- Document the full chain: Source A cites Source B cites Source C (original).
- Note the length of the chain. Longer chains carry higher distortion risk.

### Step 4: Check for Circular Citations
- A circular citation occurs when Source A cites Source B, and Source B cites Source A, or when multiple sources all cite each other in a loop.
- Also check for "hidden circularity": multiple sources that appear independent but all trace back to a single original source.
- If the chain is circular, the apparent corroboration is false. You have one source, not multiple.

### Step 5: Verify Fidelity at Each Link
- At each link in the chain, check: Does the citing source accurately represent what the cited source says?
- Common fidelity failures:
  - Paraphrasing that changes meaning.
  - Selective quoting that removes important caveats.
  - Citing a source for a claim it does not actually make.
  - Citing a source that has been retracted or corrected.

### Step 6: Assess Chain Integrity
- **Intact chain**: Every link checks out, fidelity is maintained, and the origin is a credible primary source. High confidence.
- **Broken chain**: One or more links cannot be verified, a cited source does not support the claim, or the origin cannot be located. Low confidence.
- **Circular chain**: Apparent corroboration collapses into a single source. Treat as single-source evidence.
- **Degraded chain**: The claim has been subtly altered through paraphrasing at each link. Moderate confidence; prefer the original wording.

### Step 7: Document and Report
- Record the full chain with assessment at each link.
- Flag broken, circular, or degraded chains.
- Recommend whether the claim can be used as evidence and at what confidence level.

## Outputs
- A documented citation chain for each critical claim.
- Fidelity assessment at each link.
- Chain integrity rating (intact, broken, circular, degraded).
- Recommendation on the claim's usability as evidence.

## Common Pitfalls
- Assuming that because a claim appears in many sources, it must be well-supported. Amplification is not corroboration.
- Stopping the chain trace at the first secondary source instead of reaching the primary.
- Not checking whether cited sources have been retracted, corrected, or superseded.
- Ignoring paraphrasing distortions because the "gist" seems right.
- Treating a dead link (source no longer available) as a minor issue rather than a chain break.
- Missing circular citations because the loop involves 3+ sources.

## Related Frameworks
- **Primary-Secondary Split**: The chain trace identifies which link is primary.
- **Authority Proximity**: Each link in the chain increases distance from the origin.
- **Citation Integrity**: Detailed verification at each link in the chain.
- **Cross-Source Verification**: True corroboration requires independent chains, not shared origins.
- **Claim Grid**: Chain integrity feeds into the confidence column.
