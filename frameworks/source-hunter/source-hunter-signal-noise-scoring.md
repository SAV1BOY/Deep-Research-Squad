# Signal-Noise Scoring Framework

## Purpose
Provide a systematic, repeatable method for scoring each source on its signal-to-noise ratio. Separates high-value sources that directly address the research question from low-value sources that add volume without substance. Enables prioritization of limited review time.

## When to Use
- When a search returns many results and triage is needed.
- When deciding which sources to read in full versus skim or discard.
- When comparing sources that appear to cover similar ground.
- When building a shortlist of sources for deep analysis.

## Inputs
- A set of sources from search results.
- The specific research question or sub-question being addressed.
- Scope boundaries (temporal, geographic, domain).

## Process

### Step 1: Define Signal for This Research Task
- Signal is information that directly advances answering the research question.
- Before scoring, write a one-sentence definition of what counts as signal for this task.
- Example: "Signal is quantitative evidence of market share shifts in European SaaS between 2022-2025."

### Step 2: Score Each Source on Five Factors
Rate each factor from 1 (lowest) to 5 (highest):

**Factor 1: Relevance**
- How directly does this source address the research question?
- 5 = Directly on topic. 3 = Tangentially related. 1 = Only keyword overlap.

**Factor 2: Authority**
- How credible is the source, author, and publisher?
- 5 = Top-tier primary source or recognized expert. 3 = Reputable but not specialist. 1 = Unknown or questionable provenance.

**Factor 3: Specificity**
- How specific and detailed is the information provided?
- 5 = Precise data, named sources, concrete evidence. 3 = General claims with some support. 1 = Vague assertions without evidence.

**Factor 4: Recency**
- How current is the source relative to the research need?
- 5 = Published within the required time window. 3 = Slightly outside but still relevant. 1 = Outdated for this research context.
- Note: For foundational theory, older sources may still score 5. Use the Freshness Matrix to calibrate.

**Factor 5: Independence**
- Is this source independent of other sources in the evidence set?
- 5 = Fully independent; unique data or perspective. 3 = Partially overlapping with other sources. 1 = Derivative of another source already collected.

### Step 3: Calculate the Composite Score
- Sum the five factor scores. Maximum = 25, Minimum = 5.
- Classify: 20-25 = High signal (must read). 14-19 = Moderate signal (read if time permits). 8-13 = Low signal (skim only). 5-7 = Noise (discard).

### Step 4: Apply the Triage Decision
- **Must read** (20-25): Read in full, extract evidence, add to evidence file.
- **Read if time permits** (14-19): Skim for key claims, read relevant sections in detail.
- **Skim only** (8-13): Scan headings and conclusions; use only if other sources are lacking.
- **Discard** (5-7): Do not invest further time unless the search yields nothing better.

### Step 5: Adjust for Portfolio Balance
- Even if individual scores are high, check that the set of selected sources provides diverse perspectives.
- Avoid selecting only sources that confirm existing hypotheses.
- Ensure a mix of source types, authors, and methodologies.

### Step 6: Document Scores
- Record the score breakdown for each evaluated source.
- This creates an audit trail for why certain sources were prioritized or excluded.

## Outputs
- A scored and ranked list of sources.
- Triage classification (must read, read if time, skim, discard) for each source.
- Score breakdown showing which factors drove the rating.
- Portfolio balance assessment.

## Common Pitfalls
- Scoring relevance based on title alone without checking content.
- Inflating authority scores for well-known publishers when the specific article is weak.
- Ignoring independence, leading to an evidence base that appears broad but traces to one origin.
- Not defining signal before scoring, causing inconsistent ratings across sources.
- Discarding moderate-signal sources too aggressively when they offer the only dissenting view.
- Scoring recency uniformly without considering whether the field requires freshness.

## Related Frameworks
- **Freshness Matrix**: Calibrates the recency factor based on field dynamics.
- **Authority Proximity**: Feeds into the authority factor of the score.
- **Primary-Secondary Split**: Source category informs the authority and independence factors.
- **Publication Chain**: Reveals whether apparently independent sources share a common origin.
- **Claim Grid**: High-signal sources feed evidence into the claim grid.
