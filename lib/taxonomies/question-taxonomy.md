# Question Taxonomy

## Purpose

Classifies research questions by type to guide methodology, evidence requirements,
and deliverable format.

## Categories

### 1. Factual Questions
Seek objective, verifiable information.
- **Definitional** - "What is X?"
- **Descriptive** - "How does X work?"
- **Quantitative** - "How much/many?"
- **Existence** - "Does X support Y?"

**Example:** "What consistency model does CockroachDB use?"

### 2. Comparative Questions
Evaluate relative merits of options.
- **Binary Comparison** - "Is X better than Y for Z?"
- **Multi-Option** - "Which of X, Y, Z is best for W?"
- **Trade-off** - "What are the trade-offs between X and Y?"
- **Fit Assessment** - "Does X meet our requirements?"

**Example:** "How does ClickHouse compare to Druid for real-time analytics?"

### 3. Causal Questions
Understand cause-and-effect relationships.
- **Root Cause** - "Why does X happen?"
- **Impact** - "What happens if we do X?"
- **Dependency** - "Does X depend on Y?"

**Example:** "Why does query latency increase above 10TB?"

### 4. Predictive Questions
Forecast future states or outcomes.
- **Trend** - "Where is X heading?"
- **Scenario** - "What if X happens?"
- **Feasibility** - "Can we achieve X by Y?"

**Example:** "Will PostgreSQL close the OLAP gap within 2 years?"

### 5. Evaluative Questions
Judge or assess against criteria.
- **Quality** - "How good is X?"
- **Risk** - "How risky is X?"
- **Readiness** - "Is X ready for production?"
- **Suitability** - "Is X appropriate for our context?"

**Example:** "Is CockroachDB mature enough for payment processing?"

### 6. Strategic Questions
Seek guidance on direction or approach.
- **Approach** - "How should we do X?"
- **Priority** - "What should we do first?"
- **Architecture** - "How should we structure X?"

**Example:** "Should we adopt a polyglot persistence strategy?"

## Usage

Classify each question in the tree to select research patterns, set evidence
requirements, define deliverable format, and estimate research effort.
