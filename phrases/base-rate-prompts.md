# Base Rate Prompts - Language Patterns

## Purpose

These language patterns help agents incorporate base rate thinking into
research analysis. Base rates ground predictions and assessments in
historical frequency, preventing overconfidence in individual cases.

## What Is a Base Rate

A base rate is the historical frequency of an outcome in a reference class.
Before assessing a specific case, ask: "How often does this type of thing
happen in general?"

## Establishing Base Rates

### Finding the Reference Class

- "The appropriate reference class for this prediction is [class]."
- "To assess this, we compare against [N] similar cases from [timeframe]."
- "The reference class is [type of event] in [context]. Historical frequency: [rate]."
- "We identified [N] comparable situations. The base rate for [outcome] is [X]%."

### Stating Base Rates

- "Historically, [X]% of similar [predictions / initiatives / events] resulted in [outcome]."
- "The base rate for success in this category is [rate]."
- "In [N] comparable cases, the predicted outcome occurred [M] times ([X]%)."
- "The historical average for [metric] in this category is [value]."

## Applying Base Rates

### Adjusting from Base Rate

- "The base rate is [X]%. Specific factors in this case [increase / decrease] our estimate."
- "Starting from the base rate of [X]%, we adjust [upward / downward] because [reasons]."
- "Three factors distinguish this case from the base rate: [1], [2], [3]."
- "After adjusting for case-specific factors, our estimate is [Y]%, compared to the base rate of [X]%."

### When the Case Matches the Base Rate

- "This case has no distinctive features that would suggest deviation from the base rate."
- "The base rate of [X]% is our best estimate in the absence of differentiating information."
- "Nothing in the evidence justifies departing from the base rate."

### When the Case Differs from the Base Rate

- "This case differs from the reference class in [specific ways], warranting an adjustment."
- "The base rate may underestimate [overestimate] here because [reason]."
- "We assign a probability of [Y]%, [higher / lower] than the base rate, due to [factors]."

## Base Rate Challenges

### Narrow vs. Broad Reference Classes

- "Using a narrow reference class ([specific]), the rate is [X]%. Using a broader class, it is [Y]%."
- "The choice of reference class matters: [narrow class] suggests [A], while [broad class] suggests [B]."
- "We report both reference classes and note the range: [X]% to [Y]%."

### Base Rate Neglect Warning

- "Caution: the narrative is compelling, but the base rate suggests [different expectation]."
- "Individual case details can distract from the base rate. In [N] similar cases, [outcome]."
- "Before weighting case-specific factors, anchor on the base rate: [rate]."
- "The inside view suggests [optimistic / pessimistic]. The outside view (base rate) suggests [rate]."

## Reporting Format

When including base rate analysis in a deliverable:

1. **State the prediction or assessment.**
2. **Identify the reference class.**
3. **State the base rate.**
4. **List case-specific adjustments.**
5. **State the adjusted estimate.**

Example:
> "We assess a 65% probability of regulatory approval. The base rate for
> similar applications is 55%. We adjust upward because [reason 1] and [reason 2],
> partially offset by [negative factor]."

## Quality Check

- Is a base rate cited for every prediction or probability estimate?
- Is the reference class explicitly defined?
- Are case-specific adjustments justified?
- Is the final estimate anchored to the base rate?
- Are alternative reference classes considered?
