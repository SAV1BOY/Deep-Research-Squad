# Gap Disclosure Prompts - Language Patterns

## Purpose

These language patterns help agents disclose gaps in research honestly
and precisely. Disclosing gaps is not a weakness; it is a mark of rigor.
A gap disclosed is a gap managed. A gap hidden is a liability.

## Types of Gaps

### Data Gaps

- "No data is available on [topic] for [timeframe / geography / segment]."
- "The most recent data is from [date], leaving a [N]-month gap."
- "Primary data does not exist for this question. Our analysis relies on [proxy]."
- "The data covers [what is covered] but does not extend to [what is missing]."

### Source Gaps

- "We were unable to access [source type] due to [reason: paywall / classification / availability]."
- "No independent source addresses this question. Available commentary is [interested-party / speculative]."
- "Expert perspectives are limited to [N] individuals. A broader sample would strengthen this finding."
- "We consulted [N] sources. Key source types we could not access: [list]."

### Analytical Gaps

- "Our framework does not account for [factor], which may be relevant."
- "We did not perform [type of analysis] due to [time / data / scope constraints]."
- "The analysis addresses [dimension A] but not [dimension B]."
- "A causal analysis was not possible; our findings are correlational."

### Temporal Gaps

- "This analysis reflects conditions as of [date]. Events after this date are not captured."
- "A [N]-month lag exists between data collection and delivery."
- "The forecast horizon is [timeframe]. Beyond that, uncertainty increases substantially."
- "Historical data is available from [start date]. Earlier periods are not covered."

## Gap Impact Assessment Phrases

- "This gap [does / does not] materially affect the core conclusion because [reason]."
- "Closing this gap could [strengthen / weaken / change] our assessment."
- "The gap is significant: the conclusion relies on [assumption] that cannot be verified."
- "Despite this gap, the finding is robust because [alternative evidence or reasoning]."

## Gap Remediation Phrases

- "To close this gap, we recommend [specific action: interview, data purchase, analysis]."
- "This gap can be partially addressed by [proxy approach]."
- "Closing this gap would require [resource / time / access] and would [expected benefit]."
- "We recommend monitoring [indicator] as a proxy until primary data becomes available."

## Gap Reporting Format

For each significant gap, document:
1. **What is missing:** Specific description of the gap.
2. **Why it matters:** Impact on the analysis and conclusions.
3. **Why it exists:** Access limitation, data unavailability, scope constraint.
4. **How to close it:** Recommended remediation action.
5. **Workaround:** Proxy or alternative approach used, if any.

## Disclosure Placement

| Document Type      | Where to Disclose Gaps                      |
|--------------------|---------------------------------------------|
| Deep dive          | Dedicated "Limitations and Gaps" section     |
| Executive brief    | One sentence in caveats; link to full list   |
| Synthesis          | Integrated into each finding + summary       |
| Slack update       | "Note: [key gap]" at the end                 |

## Quality Check

- Are all significant gaps disclosed?
- Is the impact of each gap on the conclusion assessed?
- Are remediation recommendations provided?
- Is gap disclosure proportionate (not burying the finding under caveats)?
