# Words to Avoid in Research

## Purpose

This guide lists words and phrases that weaken research writing. Each entry
includes the problem and a suggested replacement. Avoiding these patterns
produces clearer, more credible, and more precise deliverables.

## Vague Intensifiers

| Avoid              | Problem                        | Use Instead                     |
|--------------------|--------------------------------|---------------------------------|
| "Very"             | Adds no information            | Quantify or remove              |
| "Extremely"        | Subjective intensity           | Provide a metric                |
| "Significantly"    | Ambiguous (statistical vs. colloquial) | State the magnitude or p-value |
| "Substantially"    | Undefined threshold            | State the percentage or amount  |
| "Quite"            | Vague modifier                 | Remove or quantify              |

## Weasel Words

| Avoid              | Problem                        | Use Instead                     |
|--------------------|--------------------------------|---------------------------------|
| "Some experts"     | Unattributed authority         | Name the experts or cite count  |
| "It is widely believed" | Appeal to unnamed consensus | Cite the source of the belief  |
| "Many people think"| Unquantified claim             | State the survey or source      |
| "There is evidence" | Unspecified evidence          | Cite the specific evidence      |
| "Research shows"   | Which research?                | Cite the specific study         |

## False Precision / False Hedging

| Avoid                        | Problem                      | Use Instead                    |
|------------------------------|------------------------------|--------------------------------|
| "Approximately exactly"      | Contradictory                | Choose one                     |
| "It may or may not"          | Says nothing                 | State which is more likely     |
| "Not impossible"             | Double negative, vague       | State the positive case        |
| "Could potentially"          | Redundant hedging            | "Could" or "May"              |
| "Seems to suggest"           | Stacked hedges               | "Suggests"                     |

## Filler Phrases

| Avoid                        | Problem                      | Use Instead                    |
|------------------------------|------------------------------|--------------------------------|
| "It is interesting to note"  | Editorializing               | Just state the finding          |
| "It goes without saying"     | Then do not say it           | Remove entirely                |
| "As previously mentioned"    | Redundant reference          | Remove or use a link           |
| "In order to"                | Wordy                        | "To"                           |
| "At this point in time"      | Wordy                        | "Now" or "Currently"           |
| "Due to the fact that"       | Wordy                        | "Because"                      |

## Editorializing Words

| Avoid              | Problem                        | Use Instead                     |
|--------------------|--------------------------------|---------------------------------|
| "Obviously"        | Dismissive; if obvious, prove it | Remove or provide evidence    |
| "Clearly"          | Assumes reader agreement       | Show the evidence               |
| "Interestingly"    | Subjective; editorializing     | State the finding directly      |
| "Surprisingly"     | Injects the writer's expectation | State what was expected vs found|
| "Unfortunately"    | Value judgment                 | State the fact neutrally        |
| "Shockingly"       | Sensational                    | State the magnitude instead     |

## Absolute Claims

| Avoid              | Problem                        | Use Instead                     |
|--------------------|--------------------------------|---------------------------------|
| "Proves"           | Research rarely proves          | "Supports" or "Confirms"       |
| "Always"           | Rarely literally true           | "In all observed cases" + cite |
| "Never"            | Rarely literally true           | "In no observed case" + cite   |
| "Impossible"       | Strong claim needs strong evidence | "Highly unlikely based on..."  |
| "Guaranteed"       | No outcome is guaranteed        | State the probability           |

## Passive Constructions to Reconsider

| Avoid                        | Problem                      | Use Instead                    |
|------------------------------|------------------------------|--------------------------------|
| "It was found that"          | Hidden actor                 | "[Source] found that"          |
| "Mistakes were made"         | Avoids accountability        | "[Actor] made [specific error]"|
| "It has been suggested"      | By whom?                     | "[Author] suggested (Year)"   |
| "The decision was taken"     | By whom?                     | "[Decision-maker] decided"    |

## Quality Check

- Does the document contain any words from the avoid lists?
- Has every vague quantifier been replaced with a specific figure?
- Are all claims attributed to named sources?
- Has editorializing language been removed?
- Are absolute claims supported by evidence or softened?
