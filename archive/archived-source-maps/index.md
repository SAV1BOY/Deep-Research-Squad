# Archived Source Maps

## Purpose

This directory stores source maps from completed research engagements. A source map documents every source consulted during an engagement — which databases were searched, what queries were used, which sources yielded evidence, and which were discarded.

## Why Archive Source Maps

- **Reuse**: Future engagements on similar topics can start from proven source strategies
- **Audit trail**: Post-delivery questions about sourcing can be traced back to the original map
- **Pattern recognition**: The Knowledge Librarian identifies which source types consistently produce high-quality evidence per domain

## File Format

Each archived source map follows the structure defined in `templates/briefs/source-map-template.md` and includes:

- Engagement ID and date
- Domain and project type
- Databases and repositories searched
- Query strings used
- Sources identified, ranked, and selected
- Sources discarded with rationale
- Source diversity assessment
- Quality ratings per source

## Naming Convention

`{engagement-id}-source-map.md` (e.g., `RO-2026-03-001-source-map.md`)
