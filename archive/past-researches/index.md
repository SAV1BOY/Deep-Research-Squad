# Past Researches Archive

## Purpose

This directory stores completed research projects that have been finalized and
archived. Each entry represents a full research cycle that has concluded, with
findings delivered and no further active investigation planned.

## Directory Structure

```
past-researches/
  index.md              # This file
  YYYY-MM-topic-slug/   # One folder per archived research project
    report.md           # Final research report
    sources.md          # Collected sources and references
    notes.md            # Working notes (optional)
```

## File Naming Convention

Use the format `YYYY-MM-topic-slug` for project folders, where the date
reflects when the research was completed. Use lowercase kebab-case for the
topic slug (e.g., `2025-11-supply-chain-risks`).
