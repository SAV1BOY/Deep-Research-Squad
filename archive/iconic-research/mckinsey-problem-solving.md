# McKinsey Structured Problem Solving

## Why This Is Iconic

McKinsey's structured problem-solving approach has been the dominant
framework in management consulting for decades. It combines rigorous
logic with practical focus on decisions and actions.

## Core Framework: The Pyramid Principle

Developed by Barbara Minto at McKinsey in the 1960s:

### Structure
1. **Start with the answer**: Lead with your conclusion
2. **Group supporting arguments**: 3-5 supporting points, each MECE
3. **Support with evidence**: Data and analysis beneath each argument
4. **So what?**: Every level answers "why does this matter?"

### MECE Principle
Mutually Exclusive, Collectively Exhaustive:
- **Mutually Exclusive**: No overlap between categories
- **Collectively Exhaustive**: Nothing is missing
- Applied to problem decomposition, analysis structure, and recommendations

## The Seven Steps of Problem Solving

### 1. Define the Problem
- State the problem as a question
- Identify the decision-maker
- Specify constraints and boundaries
- Agree on success criteria

### 2. Disaggregate the Problem
- Break into component parts using issue trees
- Ensure MECE structure
- Identify which components matter most (80/20)

### 3. Prioritize
- Which components have the biggest impact?
- Where is data available?
- What can be influenced?
- Focus on the vital few, not the trivial many

### 4. Build a Work Plan
- What analysis is needed for each priority area?
- What data is required?
- Who does what by when?

### 5. Conduct Analysis
- Hypothesis-driven: start with a hypothesis, test it
- 80/20 rule: get 80% of the answer with 20% of the effort
- Triangulate: multiple approaches to the same question

### 6. Synthesize Findings
- What does the analysis mean?
- What patterns emerge across components?
- How confident are we in each finding?

### 7. Communicate
- Pyramid structure: answer first
- One story per chart
- Recommendations tied to findings

## Lessons for Deep Research Squad

### What We Adopt
- Hypothesis-driven research (not open-ended exploration)
- MECE problem decomposition
- Answer-first communication
- 80/20 prioritization of research effort

### What We Adapt
- Issue trees → research question decomposition in briefs
- Work plan → research brief with agent assignments
- Synthesis → evidence tables with confidence scoring
- Communication → compressed executive summaries

### What We Reject
- Overconfidence in frameworks (reality is messier than MECE)
- Ignoring contradictions to maintain clean narrative
- Prioritizing persuasion over accuracy
