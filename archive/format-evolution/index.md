# Format Evolution Archive

## Purpose

This directory records the history of changes to output formats, report
structures, and deliverable templates. It captures how the squad's research
outputs have evolved over time, preserving examples of previous formats
alongside the reasoning behind each transition.

## Directory Structure

```
format-evolution/
  index.md                      # This file
  YYYY-MM-DD-format-change.md   # Description of the format change
  samples/                      # Before/after samples (optional)
```

## File Naming Convention

Use the format `YYYY-MM-DD-format-change.md` where the date reflects when the
new format was adopted. The suffix should identify which format area changed
in lowercase kebab-case (e.g., `2025-09-01-report-header-redesign.md`).

Each file should include: affected output type, previous format summary, new
format summary, and migration notes if applicable.
