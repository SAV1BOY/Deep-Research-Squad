# Methodology Changes Archive

## Purpose

This directory tracks the evolution of research methodologies used by the squad.
Each record captures what changed, why it changed, and what methodology it
replaced. This provides an audit trail for process improvements and helps avoid
repeating past mistakes.

## Directory Structure

```
methodology-changes/
  index.md                    # This file
  YYYY-MM-DD-change-slug.md   # One file per methodology change
```

## File Naming Convention

Use the format `YYYY-MM-DD-change-slug.md` where the date is when the change
was adopted. The slug should briefly describe the nature of the change in
lowercase kebab-case (e.g., `2025-10-15-switched-to-tiered-sourcing.md`).

Each file should include: previous methodology, new methodology, rationale for
the change, and expected impact.

## Example Entries

```
# (No methodology changes recorded yet)
#
# Future entries will appear as:
#   2026-01-10-added-peer-review-step.md
#   2026-02-20-revised-source-scoring.md
#   2026-03-05-dropped-manual-dedup.md
```
