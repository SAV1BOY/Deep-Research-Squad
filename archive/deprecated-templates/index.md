# Deprecated Templates Archive

## Purpose

This directory holds templates that have been retired from active use. Templates
are moved here when they are replaced by improved versions or when the workflow
they supported is no longer relevant. They are preserved for reference and
rollback purposes.

## Directory Structure

```
deprecated-templates/
  index.md                      # This file
  template-name-vN.md           # Retired template with version suffix
  template-name-vN.metadata.md  # Deprecation context (optional)
```

## File Naming Convention

Append the last active version number to the template filename using the format
`template-name-vN.md` (e.g., `research-brief-v2.md`). If recording why the
template was deprecated, use a `.metadata.md` suffix.
