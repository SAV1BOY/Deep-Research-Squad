# Squad Retrospectives Archive

## Purpose

This directory stores retrospective notes from squad review sessions. Each
retrospective captures what went well, what could be improved, and action items
agreed upon by the team. These records support continuous improvement and
provide historical context for process decisions.

## Directory Structure

```
squad-retrospectives/
  index.md                  # This file
  YYYY-MM-DD-retro.md       # One file per retrospective session
```

## File Naming Convention

Use the format `YYYY-MM-DD-retro.md` where the date is when the retrospective
was held. If multiple sessions occur on the same day, append a sequence number
(e.g., `2026-03-10-retro-2.md`).

Each file should include: date, participants, what went well, what needs
improvement, and action items with owners.

## Example Entries

```
# (No retrospectives recorded yet)
#
# Future entries will appear as:
#   2026-01-31-retro.md
#   2026-02-28-retro.md
#   2026-03-13-retro.md
```
