# Case Studies Index

## Purpose
Central index for case studies collected and developed during research
projects. Case studies provide rich contextual evidence and serve as
reference examples for future analysis.

## Directory Structure
```
case-studies/
  {domain}/
    {case-id}/
      summary.md     - Executive summary of the case
      details.md     - Full case narrative and analysis
      evidence/      - Supporting evidence files
      lessons.md     - Lessons extracted from the case
```

## Naming Convention
Case IDs follow: `CS-{domain-code}-{YYYY}-{NNN}`

## Case Study Template
Each case study should include:
- Background and context
- Problem or opportunity description
- Actions taken and decision rationale
- Outcomes and measurable results
- Lessons learned and transferability assessment

## Cross-References
- Insights derived: see `data/registries/insight-registry.yaml`
- Patterns observed: see `data/registries/domain-pattern-registry.yaml`
- Lessons learned: see `data/registries/lessons-learned-registry.yaml`

## Quality Standards
- Cases must have verifiable sources for key facts
- Outcomes must be documented with actual data, not estimates
- Transferability assessment must consider context differences
- Both successes and failures should be represented
