### Architecture
- Orchestrator-Worker pattern (Anthropic multi-agent design)
- Pipeline: Question → Scope → Source Plan → Evidence → Contradictions → Synthesis → Models → Decision → Memory
- Quality gates at every pipeline stage
- Cross-squad integration with 10 specialized squads
- RalphLoop (R1-R18) iterative research cycle

### Prompt Engineering
- Hierarchical Role Modeling (HRM)
- Chain-of-Thought (CoT) reasoning protocols
- ReAct (Reasoning + Acting) patterns
- Role-based prompting with identity anchors
- Escalation and handoff protocols
- Anti-pattern documentation
