# Phase 3: Data Collection

## Purpose
Execute the source plan systematically, gathering evidence for each
sub-question while maintaining chain-of-custody documentation for
every piece of data collected.

## Inputs
- Source plan and collection schedule from Phase 2
- Access credentials and permissions
- Collection templates and extraction forms
- Quality standards for each evidence type

## Process Steps
1. Set up collection infrastructure (folders, trackers, tools).
2. Begin collection in priority order from the source plan.
3. For each source, extract relevant data using structured forms.
4. Record metadata: date accessed, version, author, URL/location.
5. Assess initial quality and flag questionable data immediately.
6. Cross-reference findings against other sources in real-time.
7. Update the source registry with collection status.
8. Conduct daily stand-ups to surface blockers and adjust.

## Quality Gates
- [ ] Every data point has a traceable source citation
- [ ] Collection forms are complete with no missing fields
- [ ] Data quality flags are raised within 24 hours of detection
- [ ] At least 80% of planned sources have been collected
- [ ] Cross-referencing has begun for high-priority claims
- [ ] Source registry is current and accurate

## Outputs
- Raw evidence files organized by sub-question
- Completed collection forms with metadata
- Updated source registry with status
- Data quality flag report
- Preliminary cross-reference notes
- Collection completion summary
