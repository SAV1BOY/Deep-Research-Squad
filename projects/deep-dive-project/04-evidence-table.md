# Phase 4: Evidence Table

## Purpose
Organize all collected evidence into a structured evaluation framework.
Assess each piece of evidence for strength, relevance, and reliability
to build the foundation for synthesis.

## Inputs
- Raw evidence files from Phase 3
- Collection metadata and quality flags
- Sub-question hierarchy from Phase 1
- Source reliability assessments from Phase 2

## Process Steps
1. Create the master evidence table with standard columns.
2. Enter each evidence item with its sub-question mapping.
3. Rate evidence strength: strong, moderate, weak, anecdotal.
4. Rate evidence relevance: direct, indirect, contextual.
5. Identify corroborating evidence clusters.
6. Flag orphan evidence that supports no current sub-question.
7. Calculate evidence coverage per sub-question.
8. Highlight sub-questions with insufficient evidence.

## Quality Gates
- [ ] Every evidence item is rated for strength and relevance
- [ ] All evidence is mapped to at least one sub-question
- [ ] Corroboration clusters are identified and documented
- [ ] Evidence gaps are explicitly noted per sub-question
- [ ] No evidence items lack source citations
- [ ] Confidence levels are assigned per sub-question

## Outputs
- Master evidence table (structured spreadsheet or document)
- Evidence coverage heat map by sub-question
- Corroboration cluster report
- Evidence gap analysis
- Confidence level summary per sub-question
- Updated claim registry entries
