# Phase 5: Contradiction Map

## Purpose
Systematically identify, document, and resolve contradictions within
the evidence base. Contradictions often reveal the most important
insights and must be addressed before synthesis.

## Inputs
- Master evidence table from Phase 4
- Source reliability assessments
- Corroboration cluster report
- Domain expertise and mental models

## Process Steps
1. Scan the evidence table for directly conflicting claims.
2. Categorize each contradiction by type: factual, interpretive,
   methodological, temporal, or contextual.
3. Assess the strength of evidence on each side.
4. Investigate root causes of each contradiction.
5. Determine resolution path: one side wins, both partially right,
   or genuine uncertainty remains.
6. Document unresolvable contradictions with confidence bounds.
7. Update evidence ratings based on contradiction analysis.
8. Feed resolved contradictions back into the evidence table.

## Quality Gates
- [ ] All contradictions are identified and categorized
- [ ] Each contradiction has a documented resolution or rationale
- [ ] Evidence ratings are updated post-resolution
- [ ] Unresolvable contradictions are flagged with uncertainty bounds
- [ ] No contradictions are ignored or hand-waved away
- [ ] Contradiction registry is updated with all entries

## Outputs
- Contradiction map (visual and tabular)
- Resolution notes for each contradiction
- Updated evidence table with revised ratings
- Unresolved contradiction list with uncertainty bounds
- Updated contradiction registry entries
- Key insight notes from contradiction analysis
