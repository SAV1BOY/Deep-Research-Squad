# Phase 6: Synthesis

## Purpose
Integrate all evidence, resolved contradictions, and analytical insights
into coherent findings that directly answer each sub-question and the
primary research question.

## Inputs
- Updated evidence table from Phase 5
- Contradiction map and resolution notes
- Question hierarchy from Phase 1
- Confidence levels per sub-question
- Domain patterns and prior knowledge

## Process Steps
1. Answer each sub-question individually with supporting evidence.
2. Assign a confidence level (high/medium/low) to each answer.
3. Identify emergent themes that span multiple sub-questions.
4. Build the narrative arc connecting sub-question answers.
5. Synthesize sub-answers into a primary question response.
6. Document assumptions and their sensitivity.
7. Identify what would change the conclusion (pre-mortem).
8. Peer review the synthesis with a fresh set of eyes.

## Quality Gates
- [ ] Every sub-question has a direct, evidence-backed answer
- [ ] Confidence levels are justified with evidence quality metrics
- [ ] Emergent themes are supported by multiple evidence streams
- [ ] Assumptions are explicit and sensitivity-tested
- [ ] Pre-mortem risks are documented
- [ ] Peer review feedback is incorporated
- [ ] Insight registry is updated with new findings

## Outputs
- Sub-question answer sheets with evidence citations
- Confidence assessment summary
- Emergent themes report
- Assumption sensitivity analysis
- Primary research question answer (draft)
- Updated insight registry entries
