# Phase 2: Source Plan

## Purpose
Identify, evaluate, and prioritize all potential data sources for the
investigation. Create a systematic collection strategy that maximizes
evidence quality while respecting time constraints.

## Inputs
- Question hierarchy from Phase 1
- Evidence type requirements per sub-question
- Known source repositories and databases
- Access constraints and permissions
- Budget for paid sources or expert consultations

## Process Steps
1. Brainstorm all possible sources per sub-question.
2. Classify sources by type: primary, secondary, expert, data.
3. Assess each source for reliability, recency, and relevance.
4. Check access availability and lead times.
5. Create a source matrix mapping sources to sub-questions.
6. Identify gaps where no quality source exists.
7. Plan mitigation for source gaps (proxies, triangulation).
8. Sequence source collection to front-load high-value items.

## Quality Gates
- [ ] Every sub-question has at least two independent sources
- [ ] Source reliability is assessed using a standard rubric
- [ ] No single-source dependencies for critical claims
- [ ] Access and lead times are confirmed, not assumed
- [ ] Source gaps are documented with mitigation plans
- [ ] Collection sequence respects dependencies

## Outputs
- Source matrix (sources x sub-questions)
- Source reliability assessments
- Collection schedule with owners
- Gap analysis and mitigation plan
- Source registry entries (for data/registries/)
