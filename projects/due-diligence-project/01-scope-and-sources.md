# Phase 1: Scope and Sources

## Purpose
Define the detailed investigation scope per diligence dimension and
map all available information sources. Create a systematic collection
strategy prioritized by risk and deal-breaker relevance.

## Inputs
- Due diligence charter from Phase 0
- Deal-breaker criteria list
- Target entity public records and filings
- Data room access (if available)
- Industry-specific diligence checklists

## Process Steps
1. Break each diligence dimension into specific investigation areas.
2. Map deal-breakers to the specific areas that would surface them.
3. Prioritize investigation areas by risk impact and probability.
4. Identify all available sources per investigation area.
5. Classify sources: data room, public records, interviews, expert.
6. Assess source reliability and potential bias for each.
7. Plan the collection sequence: front-load deal-breaker areas.
8. Create the investigation checklist with source assignments.

## Quality Gates
- [ ] All diligence dimensions are decomposed into specific areas
- [ ] Deal-breaker areas are prioritized for early investigation
- [ ] Source list is comprehensive across all dimensions
- [ ] Source reliability and bias assessments are documented
- [ ] Collection sequence prioritizes risk-revealing sources
- [ ] No dimension has zero identified sources
- [ ] Investigation checklist is complete and assigned

## Outputs
- Detailed scope breakdown by dimension and area
- Source map per investigation area
- Prioritized investigation checklist
- Source reliability and bias assessments
- Collection sequence and schedule
- Data room document request list
- Updated source registry entries
