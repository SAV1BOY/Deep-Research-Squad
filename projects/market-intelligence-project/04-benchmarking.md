# Phase 4: Benchmarking

## Purpose
Establish quantitative and qualitative benchmarks against competitors
and market standards. Identify performance gaps, areas of advantage,
and opportunities for differentiation.

## Inputs
- Competitor profiles from Phase 2
- Trend analysis from Phase 3
- Internal performance data and capabilities
- Industry benchmarks and best practice standards
- Customer satisfaction and NPS data where available

## Process Steps
1. Define benchmarking dimensions aligned with strategic priorities.
2. Select benchmark peers (direct competitors, aspirational leaders).
3. Collect quantitative metrics for each dimension.
4. Normalize data for fair comparison across different-sized players.
5. Score each player on each dimension using a consistent scale.
6. Create spider/radar charts for visual comparison.
7. Identify performance gaps and areas of competitive advantage.
8. Prioritize gaps by strategic importance and closability.

## Quality Gates
- [ ] Benchmarking dimensions cover all strategically relevant areas
- [ ] Data normalization method is documented and defensible
- [ ] Scoring uses a consistent, repeatable methodology
- [ ] At least three peers are included for each benchmark
- [ ] Gaps are prioritized by both importance and feasibility
- [ ] Data recency is documented for all metrics

## Outputs
- Benchmarking scorecard with all dimensions
- Spider/radar charts per competitor cluster
- Gap analysis with prioritization
- Competitive advantage inventory
- Opportunity identification report
- Updated metrics and scorecard registries
