# Phase 5: Follow-Up

## Purpose
Establish monitoring, feedback loops, and follow-up protocols to track
the decision outcome. Capture lessons learned to improve future decision
support engagements.

## Inputs
- Decision recommendation and implementation plan from Phase 4
- Reversal triggers and monitoring indicators
- Stakeholder feedback on the decision process
- Actual decision made by the decision-maker
- Implementation progress data

## Process Steps
1. Record the actual decision made (may differ from recommendation).
2. Set up monitoring for reversal triggers and key indicators.
3. Schedule follow-up check-ins at defined intervals.
4. Track implementation progress against the plan.
5. Collect stakeholder feedback on the decision support process.
6. Compare actual outcomes to scenario model predictions.
7. Document what the research got right and wrong.
8. Capture lessons learned for methodology improvement.
9. Update all organizational registries with final data.

## Quality Gates
- [ ] Actual decision is recorded with rationale if different
- [ ] Monitoring is active for all defined indicators
- [ ] Follow-up schedule is in the team calendar
- [ ] Implementation tracking is systematic
- [ ] Feedback collection covers process and content quality
- [ ] Outcome comparison is honest, including prediction errors
- [ ] Lessons learned are specific and actionable

## Outputs
- Decision record (recommended vs actual)
- Monitoring dashboard or tracking system
- Follow-up schedule with assigned owners
- Implementation progress reports
- Stakeholder feedback summary
- Outcome vs prediction comparison
- Lessons learned document
- Updated decision, lessons-learned, and methodology registries

## Next Phase
This is the final phase. Maintain monitoring on the defined cadence
and trigger new research if reversal conditions are approached.
