# Phase 3: Options Analysis

## Purpose
Evaluate each decision option against all criteria using the collected
evidence. Apply structured analytical techniques to ensure objectivity
and surface trade-offs transparently.

## Inputs
- Evidence base from Phase 2
- Decision criteria with priority weights
- Known options and any new options discovered
- Risk tolerance profile from Phase 0
- Decision analysis framework (weighted scoring, decision matrix)

## Process Steps
1. Score each option on each criterion using evidence.
2. Apply criterion weights to calculate composite scores.
3. Conduct sensitivity analysis: how do results change with weights?
4. Identify critical trade-offs between top options.
5. Assess risks specific to each option.
6. Model best-case, expected-case, and worst-case outcomes.
7. Check for options not yet considered (expand the option space).
8. Document the analysis methodology and assumptions.

## Quality Gates
- [ ] Every option is scored on every criterion with evidence
- [ ] Scoring uses a consistent, documented methodology
- [ ] Sensitivity analysis tests at least 3 weight variations
- [ ] Trade-offs are transparently presented, not hidden
- [ ] Risk assessment covers both probability and impact
- [ ] Scenario modeling includes realistic downside cases
- [ ] Option space expansion check is documented
- [ ] Assumptions are explicit and sensitivity-tested

## Outputs
- Decision matrix with weighted scores
- Sensitivity analysis results and visualizations
- Trade-off analysis per top option pair
- Risk assessment per option
- Scenario model outputs (best/expected/worst)
- Option space expansion notes
- Updated decision and insight registries
