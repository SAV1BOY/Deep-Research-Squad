# Phase 4: Recommendation

## Purpose
Deliver a clear, evidence-based recommendation to the decision-maker.
Present the analysis transparently, acknowledge uncertainties, and
provide implementation guidance.

## Inputs
- Options analysis and decision matrix from Phase 3
- Sensitivity and scenario analysis results
- Risk assessments per option
- Decision-maker's criteria and risk tolerance
- Stakeholder impact considerations

## Process Steps
1. State the recommended option with clear rationale.
2. Summarize the evidence chain supporting the recommendation.
3. Present the top alternative and why it was not recommended.
4. Document conditions under which the recommendation changes.
5. Outline implementation steps for the recommended option.
6. Define decision reversal triggers and monitoring indicators.
7. Address stakeholder concerns and communication needs.
8. Prepare the decision brief for the decision-maker.

## Quality Gates
- [ ] Recommendation is clear, specific, and actionable
- [ ] Evidence chain from finding to recommendation is traceable
- [ ] Alternatives are fairly presented with reasons for ranking
- [ ] Conditions for changing the recommendation are explicit
- [ ] Implementation steps are practical and sequenced
- [ ] Reversal triggers are objective and observable
- [ ] Decision brief matches the evidence sufficiency standard

## Outputs
- Decision recommendation document
- Evidence chain summary
- Alternative options comparison
- Condition and reversal trigger specification
- Implementation guidance
- Stakeholder communication plan
- Updated decision registry
