# Phase 2: Inclusion and Exclusion Screening

## Purpose
Apply predefined inclusion and exclusion criteria to screen search
results. Reduce the corpus to relevant, quality studies through a
transparent, two-stage screening process.

## Inputs
- Raw search results from Phase 1
- Review question and scope boundaries
- Predefined inclusion/exclusion criteria
- Reference manager with deduplicated records
- Screening tool or spreadsheet template

## Process Steps
1. Define explicit inclusion criteria: population, intervention,
   comparison, outcome, study design, date, language.
2. Define explicit exclusion criteria with rationale for each.
3. Remove duplicate records across databases.
4. Stage 1: Screen titles and abstracts against criteria.
5. Resolve disagreements through discussion or third reviewer.
6. Stage 2: Screen full texts of included records.
7. Document exclusion reasons for every full-text exclusion.
8. Create the PRISMA flow diagram showing the screening process.

## Quality Gates
- [ ] Inclusion/exclusion criteria are predefined, not post-hoc
- [ ] Duplicates are removed before screening begins
- [ ] Title/abstract screening uses at least two reviewers
- [ ] Inter-rater reliability is measured and reported
- [ ] Full-text exclusions have documented reasons
- [ ] PRISMA flow diagram accounts for all records
- [ ] No eligible studies are excluded without justification

## Outputs
- Inclusion/exclusion criteria specification
- Deduplicated record set with counts
- Title/abstract screening results
- Full-text screening results with exclusion reasons
- PRISMA flow diagram
- Inter-rater reliability statistics
- Final included studies list
- Updated citation registry
