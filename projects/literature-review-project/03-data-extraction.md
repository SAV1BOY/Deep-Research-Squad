# Phase 3: Data Extraction

## Purpose
Systematically extract relevant data from each included study using
standardized extraction forms. Ensure consistent, complete, and
accurate data capture for synthesis.

## Inputs
- Final included studies list from Phase 2
- Full-text documents for all included studies
- Data extraction form template
- Quality assessment tool appropriate for study designs
- Review question to guide extraction focus

## Process Steps
1. Design the data extraction form covering: study details,
   methods, participants, interventions, outcomes, results.
2. Pilot the extraction form on 3-5 studies and refine.
3. Extract data independently using two reviewers where feasible.
4. Resolve extraction disagreements through discussion.
5. Assess study quality using validated tools (e.g., GRADE, RoB).
6. Record quality scores alongside extracted data.
7. Contact study authors for missing or unclear data.
8. Compile the master extraction database.

## Quality Gates
- [ ] Extraction form is piloted and refined before full use
- [ ] Dual extraction is used for at least a sample of studies
- [ ] Quality assessment uses validated, appropriate tools
- [ ] Missing data attempts are documented (author contact, etc.)
- [ ] All extraction fields are complete or explicitly marked NA
- [ ] Quality scores are integrated with extracted data
- [ ] Extraction database is auditable and version-controlled

## Outputs
- Completed data extraction forms per study
- Master extraction database
- Quality assessment scores per study
- Missing data log with resolution status
- Extraction disagreement log with resolutions
- Study characteristics summary table
- Updated claim and citation registries
