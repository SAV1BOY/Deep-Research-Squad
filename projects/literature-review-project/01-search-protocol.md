# Phase 1: Search Protocol

## Purpose
Define the systematic search strategy including databases, search terms,
Boolean logic, and date ranges. Ensure the search is comprehensive,
reproducible, and free from selection bias.

## Inputs
- Literature review protocol from Phase 0
- Review question and scope boundaries
- Known landmark papers for citation chaining
- Database access and subscription inventory
- Domain-specific controlled vocabularies (MeSH, etc.)

## Process Steps
1. Identify all relevant databases for the domain.
2. Develop search strings using controlled vocabulary and free text.
3. Construct Boolean logic chains for each database.
4. Define date range, language, and publication type filters.
5. Plan supplementary searches: citation chaining, grey literature.
6. Test search strings on one database and calibrate sensitivity.
7. Document the final search strategy for each database.
8. Execute searches and export results to reference manager.

## Quality Gates
- [ ] At least three relevant databases are searched
- [ ] Search strings use both controlled vocab and free text
- [ ] Boolean logic is tested and calibrated for sensitivity
- [ ] Date range and language filters are justified
- [ ] Grey literature sources are included where appropriate
- [ ] Search strategy is fully documented for reproducibility
- [ ] Test searches retrieve known landmark papers

## Outputs
- Search strategy document per database
- Search string specifications with Boolean logic
- Database list with access confirmation
- Supplementary search plan (citation chaining, grey lit)
- Raw search results exported to reference manager
- Search yield summary (results per database)
- Updated source and methodology registries
