# 06 - Registry Update

## Purpose

This final phase ensures all intelligence gathered during the Competitor
War Room project is captured in the squad's registries for future use,
cross-referencing, and institutional memory.

## Registry Updates Required

### Source Registry
- Log all sources used during competitor mapping and deep profiling
- Include reliability ratings and access dates
- Flag sources requiring periodic re-verification
- Note any sources that were expected but unavailable

### Claim Registry
- Register all factual claims about competitors
- Include confidence levels and supporting evidence references
- Flag claims that are time-sensitive or likely to change
- Cross-reference with contradictions if applicable

### Insight Registry
- Capture strategic insights from moat analysis
- Record competitive dynamics patterns identified
- Document non-obvious findings and their implications
- Link insights to supporting evidence chains

### Contradiction Registry
- Document any conflicting intelligence found during profiling
- Record how contradictions were resolved (or left unresolved)
- Note which contradictions carry strategic significance

### Decision Registry
- Log any decisions or recommendations made
- Include the evidence basis for each recommendation
- Record stakeholder responses to action plans
- Track implementation status of response scenarios

## Process

### Step 1: Gather All Artifacts
Collect all working documents, notes, and data files created during
the project. Nothing should exist only in an agent's working memory.

### Step 2: Extract Registry Entries
For each artifact, identify registerable items:
- New sources discovered
- Claims made or validated
- Insights generated
- Contradictions identified
- Decisions recommended

### Step 3: Format and File
Use the standard registry formats defined in `data/registries/`.
Assign proper IDs following `docs/naming-conventions.md`.

### Step 4: Cross-Reference
Link related entries across registries. A claim should reference its
sources. An insight should reference its supporting claims.

### Step 5: Quality Check
- Are all sources logged with reliability ratings?
- Are all claims backed by cited evidence?
- Are insights linked to their evidence chains?
- Are contradictions documented with resolution status?
- Are decision recommendations traceable to evidence?

## Completion Criteria

This phase is complete when all registries are updated and the project
can be fully reconstructed from registry entries alone.
