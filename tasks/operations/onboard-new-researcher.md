# Onboard New Researcher

## Purpose
Onboard a new researcher or agent into the squad by providing them with the context, knowledge, tools, and protocols needed to contribute effectively to research projects.

## When to Use
- When a new agent joins the research squad
- When an existing agent takes on a new research role
- When a temporary or guest researcher joins for a specific project
- When reactivating an agent that has been inactive for an extended period
- During squad restructuring that changes agent responsibilities

## Agents Involved
- **Lead**: DeepResearch Chief
- **Executing**: Domain Specialist, Source Hunter
- **Supporting**: All experienced squad agents (as mentors)
- **Onboarding**: The new researcher being onboarded

## Inputs
- New researcher's background, expertise, and intended role
- Squad operational documentation (processes, protocols, standards)
- Current research projects and upcoming priorities
- Domain knowledge base relevant to the researcher's assignments
- Source library and tool access requirements

## Steps
1. Review the new researcher's background and expertise profile
2. Define their initial role, responsibilities, and reporting relationships
3. Provide access to all squad tools, registries, and knowledge bases
4. Walk through the squad's research methodology and quality standards
5. Review the task library and explain how tasks are assigned and executed
6. Introduce the source library and source quality evaluation standards
7. Review current active research projects and their status
8. Assign a mentor from the experienced agent roster
9. Provide domain knowledge briefings relevant to initial assignments
10. Start with a supervised task to demonstrate expected quality and process
11. Review the supervised task output and provide calibration feedback
12. Confirm readiness for independent task assignment

## Quality Gates
- The new researcher has access to all required tools and resources
- They demonstrate understanding of squad methodology and standards
- The supervised task meets quality standards (or remedial guidance is provided)
- A mentor is assigned and initial check-ins are scheduled
- Domain knowledge gaps relevant to initial assignments are addressed
- The researcher confirms they feel prepared for independent work

## Outputs
- Completed onboarding checklist
- New researcher profile in the agent registry
- Access provisioning confirmation
- Supervised task review with calibration notes
- Mentor assignment documentation
- Initial assignment plan for the new researcher
- Onboarding feedback for process improvement

## Estimated Effort
- **Experienced researcher, familiar domain**: 1-2 hours
- **New researcher, familiar domain**: 2-4 hours
- **New researcher, unfamiliar domain**: 4-8 hours
