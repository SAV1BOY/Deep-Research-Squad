# Update Registries

## Purpose
Update all squad registries (source registry, agent registry, task registry, knowledge base) after a research project to capture new sources, lessons learned, and institutional knowledge for future use.

## When to Use
- After every research project is delivered
- When new sources, tools, or methodologies are discovered
- During periodic maintenance cycles
- When agent capabilities or configurations change
- After onboarding new researchers or agents

## Agents Involved
- **Lead**: Research Orchestrator
- **Executing**: Source Curator, Domain Analyst
- **Supporting**: All agents who participated in the research
- **Consulted**: Operations lead (for process registry updates)

## Inputs
- Completed research project artifacts
- Source map and source quality assessments
- Lessons learned from the research process
- New domain knowledge acquired during research
- Agent performance observations
- Process improvement suggestions

## Steps
1. Review all sources from the completed research for registry inclusion
2. Add new high-quality sources to the source registry with metadata
3. Update quality scores for existing sources based on latest assessment
4. Archive or flag sources that proved unreliable or outdated
5. Update the domain knowledge base with new findings and domain context
6. Record methodology lessons learned for the task registry
7. Update agent capability profiles based on demonstrated performance
8. Log process improvements and efficiency observations
9. Update templates or frameworks that were refined during the project
10. Cross-reference new registry entries with existing ones to avoid duplication
11. Validate all registry updates for accuracy and completeness
12. Commit registry updates and notify relevant agents of changes

## Quality Gates
- All new sources meeting quality thresholds are registered
- Registry entries have complete and accurate metadata
- No duplicate entries are created
- Lessons learned are specific and actionable
- Knowledge base updates are validated against research evidence
- All agents are notified of relevant registry changes

## Outputs
- Updated source registry with new and revised entries
- Updated domain knowledge base
- Updated agent capability profiles
- Lessons learned log
- Process improvement log
- Registry update change log

## Estimated Effort
- **Small project updates**: 30-60 minutes
- **Standard project updates**: 1-2 hours
- **Large project with many new sources**: 2-4 hours
