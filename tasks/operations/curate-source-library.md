# Curate Source Library

## Purpose
Maintain and curate the squad's source library to ensure it remains current, high-quality, well-organized, and useful as a starting point for future research projects.

## When to Use
- On a regular schedule (weekly, monthly) as part of operations maintenance
- After a batch of research projects has added many new sources
- When source quality degradation is detected (broken links, outdated data)
- When expanding into a new research domain
- When preparing the source library for a major upcoming research effort

## Agents Involved
- **Lead**: Source Curator
- **Executing**: Data Collector
- **Supporting**: Domain Analyst
- **Consulted**: Research Orchestrator (for strategic priorities)

## Inputs
- Current source registry and library
- Source usage statistics from recent research projects
- Domain landscape changes (new publications, defunct sources)
- Quality feedback from researchers who used the sources
- Strategic priorities for upcoming research

## Steps
1. Audit the current source library inventory for completeness
2. Check all sources for accessibility (broken links, paywalls, retired publications)
3. Review source quality scores and update based on recent usage feedback
4. Identify and remove or archive sources that no longer meet quality thresholds
5. Identify gaps in coverage by comparing library against domain source landscape
6. Research and add new high-quality sources to fill identified gaps
7. Update source metadata (descriptions, categories, quality scores, access notes)
8. Reorganize source categories if the taxonomy needs refinement
9. Deduplicate the library and merge entries that refer to the same source
10. Tag sources with domain and topic labels for improved discoverability
11. Generate a source library health report with statistics and recommendations
12. Communicate library updates to all research agents

## Quality Gates
- All sources in the library are accessible and current
- Quality scores reflect recent usage experience
- Coverage gaps are identified and prioritized for filling
- The library is free of duplicates and stale entries
- Metadata is complete and consistent across all entries
- The library is well-organized and easily searchable

## Outputs
- Updated and curated source library
- Source library health report
- Coverage gap analysis
- New source additions with metadata
- Archived and removed source log
- Library update communication to agents

## Estimated Effort
- **Quick maintenance pass**: 1-2 hours
- **Standard curation cycle**: 2-4 hours
- **Deep curation with gap filling**: 4-8 hours
