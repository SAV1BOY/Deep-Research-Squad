# Design Source Strategy

## Purpose
Define the source acquisition strategy for a research plan, specifying which types of sources to consult, minimum diversity requirements, and collection priorities for each branch of the question tree.

## When to Use
- After the question tree is built and scope is defined
- When planning data collection for any research branch
- When existing sources prove insufficient and a new strategy is needed
- When source bias is detected and diversification is required

## Agents Involved
- **Lead**: Source Hunter
- **Supporting**: DeepResearch Chief, Domain Specialist
- **Consulted**: Specialist researchers for domain-specific source recommendations

## Inputs
- Question decomposition tree with priority weights
- Scope and boundary definitions
- Known existing sources and their quality assessments
- Domain-specific source landscape knowledge
- Timeline and depth constraints

## Steps
1. Map each question branch to relevant source categories (academic, industry, government, primary data, expert opinion, media)
2. For each branch, define minimum source count and diversity requirements
3. Identify high-priority authoritative sources that must be consulted
4. Assess source accessibility and acquisition feasibility
5. Define search strategies for each source category (keywords, databases, repositories)
6. Establish source quality criteria (recency, authority, methodology, peer review status)
7. Plan for triangulation by ensuring at least three independent source types per branch
8. Identify potential source gaps and plan mitigation strategies
9. Set up source tracking and cataloguing approach
10. Define the source evaluation rubric (scoring criteria for quality assessment)
11. Plan for handling paywalled, restricted, or hard-to-access sources
12. Document the complete source strategy with rationale for each decision

## Quality Gates
- Every question branch has at least three independent source categories assigned
- Source diversity requirements prevent over-reliance on any single type
- High-priority authoritative sources are identified for each domain
- Source quality criteria are explicit and measurable
- Triangulation strategy is documented for key claims
- Feasibility of source acquisition is confirmed within timeline

## Outputs
- Source strategy document per branch
- Source category matrix (branches vs. source types)
- Priority source list with acquisition plan
- Source quality evaluation rubric
- Search strategy specifications

## Estimated Effort
- **Narrow topic**: 20-30 minutes
- **Moderate breadth**: 45-90 minutes
- **Broad multi-domain**: 2-3 hours
