# Allocate Research Agents

## Purpose
Assign the right agents to each branch of the research plan based on domain expertise, workload capacity, and task requirements to maximize research quality and efficiency.

## When to Use
- After the research plan, question tree, and source strategy are finalized
- When rebalancing agent assignments due to workload changes or new priorities
- When a new agent joins the squad and tasks need redistribution
- When a research branch requires specialized expertise not yet assigned

## Agents Involved
- **Lead**: DeepResearch Chief
- **Supporting**: All available research agents (for capability assessment)
- **Consulted**: Domain Specialist (for expertise matching)

## Inputs
- Finalized research plan with question tree
- Agent roster with expertise profiles and current workload
- Source strategy and collection requirements
- Timeline and milestone schedule
- Quality requirements per branch

## Steps
1. List all research tasks extracted from the question tree and source strategy
2. Classify each task by required expertise (domain knowledge, methodology, tools)
3. Review agent roster and current availability
4. Match agent expertise profiles to task requirements
5. Check for workload conflicts and capacity constraints
6. Assign primary agents to each task based on best expertise match
7. Assign backup agents for critical tasks to ensure continuity
8. Identify tasks requiring collaboration between multiple agents
9. Define handoff protocols for tasks that span agent boundaries
10. Set up communication channels and reporting schedules per agent
11. Establish escalation paths for blocked or struggling agents
12. Document assignments in the research plan and notify all agents

## Quality Gates
- Every task has a primary agent assigned with relevant expertise
- No agent is overloaded beyond reasonable capacity
- Critical tasks have backup agent assignments
- Handoff protocols are defined for cross-agent tasks
- All agents acknowledge their assignments and timelines
- Expertise gaps are identified and mitigation plans exist

## Outputs
- Agent assignment matrix (tasks vs. agents)
- Workload distribution summary
- Handoff protocol documentation
- Communication and reporting schedule
- Escalation path definitions

## Estimated Effort
- **Small squad (2-3 agents)**: 15-20 minutes
- **Medium squad (4-6 agents)**: 30-45 minutes
- **Large squad (7+ agents)**: 1-2 hours
