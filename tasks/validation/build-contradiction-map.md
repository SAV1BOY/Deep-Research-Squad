# Build Contradiction Map

## Purpose
Systematically identify, document, and analyze contradictions between sources, findings, and claims within the research to surface conflicts that require resolution before synthesis.

## When to Use
- After the evidence table is built and source mappings are complete
- When multiple sources provide conflicting information on the same topic
- As a required validation step before research synthesis
- When stakeholders report inconsistencies in preliminary findings

## Agents Involved
- **Lead**: Evidence Verifier
- **Executing**: Contrarian Analyst, Domain Specialist
- **Supporting**: Data Researcher
- **Consulted**: Source Hunter (for source credibility context)

## Inputs
- Completed evidence table with claim-source mappings
- Source registry with quality and credibility assessments
- Research findings organized by branch
- Known areas of debate or controversy in the domain

## Steps
1. Scan the evidence table for claims with contradicting source mappings
2. Identify implicit contradictions (claims that logically conflict even if not directly opposing)
3. For each contradiction, document the conflicting positions precisely
4. Identify the sources supporting each side of the contradiction
5. Assess source credibility and methodology for each conflicting source
6. Determine the type of contradiction (factual, interpretive, methodological, temporal)
7. Investigate root causes (different definitions, timeframes, methodologies, biases)
8. Attempt resolution through additional evidence or deeper source analysis
9. For unresolvable contradictions, document both positions with confidence levels
10. Assess the impact of each contradiction on overall research conclusions
11. Map contradiction clusters to identify systemic issues in the evidence base
12. Compile the contradiction map with resolution status and impact assessments

## Quality Gates
- All contradictions in the evidence table are represented in the map
- Contradiction types are correctly classified
- Root cause analysis is attempted for each contradiction
- Resolution attempts are documented even when unsuccessful
- Impact on research conclusions is assessed for each contradiction
- Both sides of unresolved contradictions are fairly represented

## Outputs
- Contradiction map with all identified conflicts
- Resolution status for each contradiction (resolved, partially resolved, unresolved)
- Root cause analysis per contradiction
- Impact assessment on research conclusions
- Contradiction cluster analysis
- Recommendations for handling unresolved contradictions in synthesis

## Estimated Effort
- **Few contradictions (3-5)**: 1-2 hours
- **Moderate contradictions (6-15)**: 2-4 hours
- **Many contradictions (15+)**: 4-8 hours
