# Run Source Audit

## Purpose
Audit the quality, diversity, and reliability of all sources used in the research to identify source-level risks such as bias concentration, over-reliance, or quality gaps that could undermine findings.

## When to Use
- As a standard validation step after collection is complete
- When source bias is suspected in the research findings
- Before final delivery to ensure source quality meets standards
- When the research relies heavily on a small number of sources
- During periodic quality reviews of ongoing research

## Agents Involved
- **Lead**: Source Hunter
- **Executing**: Evidence Verifier
- **Supporting**: Contrarian Analyst
- **Consulted**: Domain Specialist (for domain-specific source credibility)

## Inputs
- Complete source registry with all sources used in the research
- Source quality evaluation rubric
- Minimum diversity requirements from the source strategy
- Evidence table mapping sources to claims
- Domain-specific source credibility benchmarks

## Steps
1. Compile the complete inventory of sources used in the research
2. Classify each source by type (academic, industry, government, media, primary data)
3. Assess each source against the quality rubric (authority, methodology, recency, bias)
4. Calculate source diversity metrics across key dimensions (type, perspective, geography)
5. Identify source concentration risks (too many claims dependent on too few sources)
6. Check for citation chains (sources that all trace back to a single original source)
7. Evaluate perspective diversity (are different viewpoints represented?)
8. Assess temporal distribution (are sources appropriately current?)
9. Check geographic and cultural diversity where relevant to the topic
10. Compare actual source usage against the planned source strategy
11. Identify source gaps where planned categories have insufficient representation
12. Compile the source audit report with diversity metrics and risk flags

## Quality Gates
- Every source in the registry is assessed against the quality rubric
- Source diversity meets or exceeds minimum thresholds from the strategy
- Citation chain analysis identifies single-origin dependencies
- Perspective diversity is evaluated, not just source type diversity
- Source gaps relative to the plan are documented with impact assessment
- High-risk source dependencies are flagged for mitigation

## Outputs
- Source audit report with quality scores and diversity metrics
- Source diversity dashboard (type, perspective, geography, recency)
- Concentration risk flags
- Citation chain analysis
- Source gap identification with impact assessment
- Recommendations for source improvements

## Estimated Effort
- **Small source set (10-20 sources)**: 1-2 hours
- **Medium source set (20-50 sources)**: 2-4 hours
- **Large source set (50+ sources)**: 4-6 hours
