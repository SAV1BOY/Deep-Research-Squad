# Verify Claims

## Purpose
Systematically verify specific claims against primary and secondary sources, producing a verified claims register that documents the verification status and evidence for each claim.

## When to Use
- When specific factual claims need independent verification
- As part of due diligence or fact-checking processes
- When source reliability is uncertain and claims need cross-checking
- Before publishing or delivering research with high-stakes claims
- When contradictions are found and claims need resolution

## Agents Involved
- **Lead**: Evidence Verifier
- **Executing**: Data Researcher, Source Hunter
- **Supporting**: Source Hunter, OSINT Investigator
- **Reviewed by**: Contrarian Analyst

## Inputs
- List of claims to verify with their original sources
- Verification priority ranking
- Acceptable evidence standards for verification
- Access to primary and secondary source repositories
- Time constraints for verification effort

## Steps
1. Catalog all claims requiring verification with their original sources
2. Prioritize claims by importance to conclusions and risk of being incorrect
3. For each claim, identify independent verification sources
4. Execute verification searches against primary authoritative sources
5. Cross-reference against at least two independent secondary sources
6. Assess whether verification sources genuinely corroborate or merely echo
7. Check for temporal validity (is the claim still current?)
8. Check for contextual validity (does the claim apply in the stated context?)
9. Classify each claim: verified, partially verified, unverified, contradicted
10. Document the evidence chain for each verification outcome
11. Flag high-priority claims that could not be verified
12. Compile the verified claims register with full documentation

## Quality Gates
- Each claim has a clear verification status with supporting evidence
- Verification uses sources independent from the original claim source
- Echo effects are identified (multiple sources tracing to single origin)
- Temporal and contextual validity are checked, not just factual accuracy
- Unverified claims are flagged with appropriate warnings
- High-stakes claims receive the most rigorous verification

## Outputs
- Verified claims register (claim, status, evidence, confidence)
- Verification methodology documentation
- Echo source identification report
- Unverified claims warning list
- Contradicted claims analysis
- Verification coverage summary statistics

## Estimated Effort
- **5-10 claims**: 1-2 hours
- **10-25 claims**: 2-5 hours
- **25+ claims**: 5-10 hours
