# Run Literature Review

## Purpose
Execute a systematic literature review to survey, evaluate, and synthesize existing knowledge on a topic from academic, industry, and practitioner sources following a structured methodology.

## When to Use
- When a comprehensive survey of existing knowledge is required
- For academic or research-grade analysis of a topic
- When building a theoretical framework or knowledge base
- To identify consensus, debates, and gaps in current understanding
- As a foundation for original analysis or recommendations

## Agents Involved
- **Lead**: Domain Analyst
- **Executing**: Deep Researcher, Literature Specialist
- **Supporting**: Source Curator
- **Validating**: Evidence Validator, Contrarian Reviewer

## Inputs
- Research question or topic for the review
- Inclusion and exclusion criteria for sources
- Date range and source type requirements
- Known key papers, authors, or works to include
- Desired review methodology (narrative, systematic, scoping, meta-analysis)

## Steps
1. Define the review protocol (question, scope, inclusion/exclusion criteria, search strategy)
2. Design search queries for each relevant database and source repository
3. Execute systematic searches across all defined source categories
4. Screen results against inclusion and exclusion criteria (title and abstract pass)
5. Perform full-text review of included sources
6. Extract key data points, findings, and arguments from each source
7. Assess source quality using the defined evaluation rubric
8. Organize findings thematically or chronologically based on review goals
9. Identify areas of consensus, active debate, and gaps in the literature
10. Synthesize findings into a coherent narrative with evidence mapping
11. Document the review methodology for reproducibility
12. Compile the literature review report with bibliography and evidence tables

## Quality Gates
- Search strategy is comprehensive and documented for reproducibility
- Inclusion/exclusion criteria are applied consistently
- Source quality assessment uses a standardized rubric
- Key findings are traceable to specific sources
- Both supporting and contradicting evidence is included
- Gaps in the literature are explicitly identified and documented

## Outputs
- Literature review report with thematic synthesis
- Annotated bibliography with quality scores
- Evidence extraction table
- Consensus and debate map
- Gap analysis
- Methodology documentation for reproducibility

## Estimated Effort
- **Focused review (10-20 sources)**: 3-5 hours
- **Moderate review (20-50 sources)**: 5-10 hours
- **Comprehensive review (50+ sources)**: 10-20 hours
