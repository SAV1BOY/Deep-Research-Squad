# Run Deep Dive

## Purpose
Execute a full multi-layer deep dive research process, progressively building understanding from broad context through detailed analysis to nuanced insight across all branches of the question tree.

## When to Use
- For comprehensive research requests requiring depth and breadth
- When the topic requires layered investigation (surface, intermediate, deep)
- When initial findings need to be validated and expanded
- As the primary collection method for complex research questions

## Agents Involved
- **Lead**: DeepResearch Chief
- **Executing**: Data Researcher, Domain Specialist
- **Supporting**: Source Hunter, Contrarian Analyst
- **Validating**: Evidence Verifier

## Inputs
- Finalized research plan with question tree and agent assignments
- Source strategy with prioritized source lists
- Scope and boundary definitions
- Quality thresholds and confidence targets

## Steps
1. Execute Layer 1 (Broad Scan): Survey the landscape across all branches using high-level sources
2. Synthesize Layer 1 findings and identify key themes, actors, and dynamics
3. Update the question tree based on Layer 1 discoveries (add or prune branches)
4. Execute Layer 2 (Focused Investigation): Deep dive into priority branches with targeted sources
5. Cross-reference Layer 2 findings with Layer 1 context for consistency
6. Identify contradictions, gaps, and areas requiring deeper investigation
7. Execute Layer 3 (Deep Analysis): Investigate specific claims, mechanisms, and edge cases
8. Validate key findings through triangulation across independent sources
9. Document evidence chains linking sources to claims to conclusions
10. Compile all findings into a structured evidence base
11. Run initial quality checks on source diversity and evidence strength
12. Prepare the evidence base for synthesis and validation phases

## Quality Gates
- Each layer covers all in-scope branches of the question tree
- Layer transitions include explicit gap analysis
- Key claims are supported by at least three independent sources
- Contradictions are documented rather than ignored
- Source diversity meets minimum thresholds per branch
- Evidence chains are traceable from source to claim

## Outputs
- Layered evidence base (organized by branch and layer)
- Updated question tree with Layer 1/2/3 annotations
- Source registry with quality assessments
- Contradiction log
- Gap analysis report
- Preliminary findings summary

## Estimated Effort
- **Focused topic (3-4 branches)**: 2-4 hours
- **Moderate complexity (5-7 branches)**: 4-8 hours
- **High complexity (8+ branches)**: 8-16 hours
