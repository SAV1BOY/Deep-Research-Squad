# Run Benchmarking

## Purpose
Execute a structured benchmarking analysis to compare performance, practices, or outcomes against relevant standards, peers, or best-in-class examples to identify gaps and improvement opportunities.

## When to Use
- When evaluating performance against industry standards or competitors
- For identifying best practices and improvement opportunities
- When establishing performance baselines and targets
- For validating that a product, process, or outcome meets standards
- As part of continuous improvement or quality management processes

## Agents Involved
- **Lead**: Benchmarking Analyst
- **Executing**: Deep Researcher, Data Collector, Domain Analyst
- **Supporting**: Source Curator
- **Validating**: Evidence Validator

## Inputs
- Subject to benchmark (product, process, performance metric, practice)
- Benchmark type (competitive, functional, internal, best-in-class)
- Comparison peers or standards to benchmark against
- Metrics and dimensions for comparison
- Current performance data for the subject (if available)

## Steps
1. Define benchmarking objectives, scope, and comparison framework
2. Select benchmark type and identify appropriate comparison targets
3. Define metrics and measurement criteria for each dimension
4. Collect performance data for the subject entity
5. Collect comparable data for all benchmark targets
6. Normalize data to ensure fair comparison (adjust for scale, context, timing)
7. Perform gap analysis between subject and benchmark targets
8. Identify top performers and analyze their enabling practices
9. Categorize gaps by significance (critical, important, minor)
10. Develop actionable recommendations for closing critical gaps
11. Validate findings through cross-referencing and data quality checks
12. Compile benchmarking report with comparisons, gaps, and recommendations

## Quality Gates
- Comparison metrics are consistently defined and measured across all targets
- Data normalization accounts for material differences in context or scale
- Benchmark targets are genuinely comparable and relevant
- Gap analysis is quantified where possible, not just qualitative
- Recommendations are specific and actionable, not generic
- Data sources and measurement methodologies are documented

## Outputs
- Benchmarking comparison matrix with scored metrics
- Gap analysis report with severity classifications
- Best practice identification and analysis
- Improvement recommendations with priority rankings
- Performance baseline documentation
- Methodology and data source documentation

## Estimated Effort
- **Simple benchmark (2-3 targets, few metrics)**: 2-3 hours
- **Moderate benchmark (4-6 targets, multiple dimensions)**: 4-8 hours
- **Comprehensive benchmark (7+ targets, full framework)**: 8-14 hours
