# Review Source Diversity

## Purpose
Evaluate the diversity of sources used in the research across multiple dimensions to ensure findings are not skewed by over-reliance on narrow source categories, perspectives, or origins.

## When to Use
- As a standard review step after source audit completion
- When research conclusions appear one-sided or lack nuance
- When validating that source strategy requirements were met
- As part of the overall quality audit process
- When building best practices for source selection

## Agents Involved
- **Lead**: Source Hunter
- **Executing**: Evidence Verifier
- **Supporting**: Contrarian Analyst
- **Consulted**: Domain Specialist (for domain-specific diversity expectations)

## Inputs
- Source registry with all sources used in the research
- Source audit results with quality scores
- Source strategy requirements (minimum diversity thresholds)
- Evidence table showing source-to-claim mappings
- Domain knowledge about expected source landscape

## Steps
1. Catalog all sources by type (academic, industry, government, media, primary, expert)
2. Measure type diversity and compare against minimum thresholds
3. Assess perspective diversity (do sources represent different viewpoints?)
4. Evaluate geographic diversity where relevant to the research topic
5. Check temporal diversity (appropriate mix of historical and current sources)
6. Assess organizational diversity (variety of publishers and institutions)
7. Identify any single source or source cluster that dominates the evidence base
8. Check for echo chamber effects (sources citing each other in closed loops)
9. Evaluate whether dissenting or minority viewpoints are represented
10. Assess diversity across high-stakes claims specifically
11. Compare actual diversity against what the domain landscape makes available
12. Produce diversity review report with metrics and improvement recommendations

## Quality Gates
- Diversity is measured across at least five dimensions
- Minimum diversity thresholds from the source strategy are checked
- Echo chamber effects are explicitly tested for
- Dissenting viewpoints are evaluated for adequate representation
- High-stakes claims have the highest diversity requirements
- Recommendations for improvement are specific and feasible

## Outputs
- Source diversity review report with metrics per dimension
- Diversity scorecard against strategy thresholds
- Dominance and concentration analysis
- Echo chamber identification
- Dissenting viewpoint coverage assessment
- Recommendations for improving source diversity

## Estimated Effort
- **Small source set (10-20 sources)**: 30-60 minutes
- **Medium source set (20-50 sources)**: 1-2 hours
- **Large source set (50+ sources)**: 2-4 hours
