# Build Source Map

## Purpose
Create a comprehensive source map that documents all sources used in the research with their metadata, quality assessments, and relationship to specific findings, serving as a reference and audit trail.

## When to Use
- As a standard component of every research delivery package
- When stakeholders need to verify or explore the sources behind findings
- For building institutional source libraries and knowledge bases
- When preparing research for peer review or external audit
- To enable future researchers to build on existing source work

## Agents Involved
- **Lead**: Source Hunter
- **Executing**: Data Researcher, Evidence Verifier
- **Supporting**: Domain Specialist
- **Consulted**: All agents who collected sources

## Inputs
- Source registry with all sources used in the research
- Evidence table mapping sources to claims
- Source quality assessments and audit results
- Source diversity review results
- Bibliographic metadata for all sources

## Steps
1. Compile the complete source inventory from the source registry
2. Verify and standardize bibliographic metadata for every source
3. Add quality scores and credibility assessments to each source entry
4. Map each source to the specific claims and findings it supports
5. Classify sources by category, type, and role in the research
6. Document access information (URLs, databases, retrieval dates)
7. Note any access restrictions or availability limitations
8. Add usage context (how the source was used, what it contributed)
9. Identify the most influential sources (cited most, highest impact on conclusions)
10. Create a visual source map showing source relationships and clusters
11. Add recommendations for source maintenance and updates
12. Package the source map as a navigable reference document

## Quality Gates
- Every source used in the research is included in the map
- Bibliographic metadata is complete and standardized
- Source-to-claim mappings are accurate and complete
- Access information is current and functional
- Quality assessments are included for every source
- The map is navigable and useful as a reference tool

## Outputs
- Complete source map document with all entries
- Source-to-claim relationship index
- Influential source highlights
- Source category and quality distribution summary
- Access and retrieval documentation
- Source maintenance recommendations

## Estimated Effort
- **Small source set (10-20 sources)**: 1-2 hours
- **Medium source set (20-50 sources)**: 2-4 hours
- **Large source set (50+ sources)**: 4-6 hours
